# H743 信号处理端接线指南

主控为 STM32H743ZIT6。板卡按实际电源端子供电，与 F407、AD9226 和调试口共地。外部时钟配置为 PH0/PH1 上的 25 MHz 晶体。

| H743 | 对端 | 用途 |
|---|---|---|
| PA5 | F407 PA5 | SPI1 SCK，从机输入 |
| PA6 | F407 PA6 | SPI1 MISO，采样率请求和测量模型回传 |
| PA7 | F407 PA7 | SPI1 MOSI，接收采样帧 |
| PD0 | F407 PA4 | `ACQ_READY`，H743 推挽输出 |
| PA9 TX、PA10 RX | 3.3 V USB-TTL 的 RX、TX | USART1 调试，115200 baud、8N1 |
| PA13、PA14 | ST-Link SWDIO、SWCLK | SWD 烧录与调试 |
| GND | F407、USB-TTL 和 ST-Link 的 GND | 共地 |

SPI1 使用软件 NSS。上电后可在 H743 调试口检查启动状态；板间交换异常时，先核对 PD0 到 PA4、三根 SPI 线和共地，再检查帧长和 CRC。详见 [SPI1 通信协议](docs/COMMUNICATION_PROTOCOL.md)和[硬件配置](docs/HARDWARE_CONFIGURATION.md)。
