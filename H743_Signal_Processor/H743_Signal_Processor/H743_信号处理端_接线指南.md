# H743 信号处理端 接线指南

> 适用工程：`Firmware_H743`（相对于 `H743_Signal_Processor/H743_Signal_Processor`）  
> 主控：STM32H743ZIT6  
> 配套对象：STM32F407 采集端、主控 F407（预留）、PC 调试串口、ST-Link  
> 文档版本：2026-08-01

---

## 1. 电源接线

| H743 端子 | 接法 | 说明 |
|---|---|---|
| VIN / 5V | 5 V 稳压电源 | 按板载丝印选择 VIN 或 5V |
| 3.3V | 不外接 | 板载 LDO 输出，可给外设供电 |
| GND | 系统地 | 必须与 F407 采集端、AD9226、PC 共地 |

- H743 开发板一般支持 USB 5V 或 VIN 5V 输入，内部降压到 3.3V。
- 若用 ST-Link 供电，确认电流足够；算法全速运行时电流较大，建议独立 5V 供电。
- 所有 GND 先连到同一星点，避免地环流；SPI 高速线尽量短。

## 2. 晶振

| H743 引脚 | 接法 | 说明 |
|---|---|---|
| PH0 | 25 MHz 晶振一脚 | HSE 输入 |
| PH1 | 25 MHz 晶振另一脚 | HSE 输出 |
| 晶振两侧电容 | 各接 GND | 典型 10~20 pF，按晶振手册 |

固件中 PLL1 将 25 MHz HSE 倍频到 480 MHz SYSCLK。若晶振未起振，程序将卡在 `HAL_RCC_OscConfig` 后的死循环。

## 3. 与 F407 采集端接线（SPI1 全双工）

当前 `Firmware_H743` 仅通过 SPI1 与采集 F407 通信：F407 为主机，H743 为从机，**无物理 CS**，使用 PD0 ACQ_READY 流控。

| H743 引脚 | H743 功能 | 连接方向 | F407 采集端引脚 | F407 功能 |
|---|---|---|---|---|
| PA5 | SPI1_SCK | ← 输入 | PA5 | SPI1_SCK（主机时钟输出） |
| PA6 | SPI1_MISO | → 输出 | PA6 | SPI1_MISO（主机数据输入） |
| PA7 | SPI1_MOSI | ← 输入 | PA7 | SPI1_MOSI（主机数据输出） |
| PD0 | ACQ_READY（GPIO 输出） | → 输出 | PA4 | H7_READY（GPIO 输入） |
| GND | GND | — | GND | GND |

### 信号流向

- **F407 → H743 样本**：F407 在 MOSI（PA7）上发送 8192 B 样本；H743 在 MOSI（PA7）上接收。
- **H743 → F407 SET_FS 命令**：H743 在 MISO（PA6）上返回 16 B SET_FS 命令槽；F407 在 MISO（PA6）上读取。
- 全双工在同一时钟下同时完成。

### 重要提示

- **不要接 PA4/NSS**：双方使用软件 NSS，没有片选线。
- PD0 必须接 F407 PA4，否则 F407 无法知道 H743 是否已准备好接收。
- 确保 F407 软件已配置为 SPI1 主机、Mode 0、MSB first、帧长 8208 B。
- 共地必须可靠；建议用短线（<20 cm）连接 SPI 四根信号线。

## 4. 与主控 F407 接线（SPI2 RESULT，预留）

`Protocol/h743_result_protocol.*` 已实现 88 字节 RESULT 协议，但当前 `main.c` **未初始化 SPI2**。未来接入主控 F407 时可按以下引脚接线：

| H743 引脚 | H743 功能 | 连接方向 | 主控 F407 引脚 | 主控 F407 功能 |
|---|---|---|---|---|
| PB13 | SPI2_SCK | → 输出 | PB13（或 SPI2_SCK） | SPI2_SCK（从机输入） |
| PB15 | SPI2_MOSI | → 输出 | PB15（或 SPI2_MOSI） | SPI2_MOSI（从机输入） |
| PD1 | MAIN_READY（GPIO 输入） | ← 输入 | 任意 GPIO | READY 输出 |
| GND | GND | — | GND | GND |

- H743 作为 SPI2 主机，主控 F407 作为 SPI2 从机。
- 建议模式 Mode 0、8 bit、MSB first、无 CS、固定 88 B 帧。
- 主控 F407 先拉高 READY，H743 检测到高电平后启动 TX DMA。
- 当前固件未启用该链路，接线前请先补全 `MX_SPI2_Init` 与发送逻辑。

## 8. 上电检查清单

1. **电源检查**：H743 上电后 3.3V LED 亮，电流正常。
2. **晶振检查**：用示波器测 PH0/PH1，应为 25 MHz 正弦/方波。
3. **串口检查**：USB-TTL 连接 PA9，上电应打印：
   ```text
   === H743 Signal Processor (single SPI1 full-duplex) ===
   ```
4. **READY 检查**：H743 未收到 F407 时钟时 PD0 应为低；F407 准备好后 H743 会周期性拉高 PD0。
5. **SPI1 帧检查**：F407 开始发时钟后，用逻辑分析仪抓 PA5/PA6/PA7/PD0，确认 8208 B 全双工交换。
6. **算法检查**：观察 `[H7] rx=...` 中 `rx` 和 `proc` 同步增长，`err` 为 0。
7. **SPI2 预留**：确认当前固件未初始化 PB13/PB15，暂时不要接主控 F407 SPI2，避免总线冲突。

## 9. 故障排查表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| H743 上电无串口输出 | 晶振未起振、程序未跑、波特率错 | 检查 PH0/PH1、复位、波特率 115200 |
| `[H7] rx=0` | F407 未发时钟、PD0 未拉高、SPI 线序反 | 检查 PA5/PA6/PA7、PD0→PA4、共地 |
| `hal_err` 频繁非 0 | SPI 模式/位序错、帧长不对 | 确认 Mode 0、MSB first、8208 B |
| 基频测不准 | Fs 公式与 F407 不一致 | 核对 `actualFs = 168M / floor(168M/req)` |
| 串口打印乱码 | USB-TTL 与 H743 不共地、波特率错 | 共地、确认 115200 |
| SPI2 接主控无数据 | 固件未初始化 SPI2 | 先补全代码再接线 |

---

## 10. 备注

- H743 与 F407 采集端必须共地；SPI 线越短越好，建议在 20 cm 以内。
- 当前固件未使用片选信号，所有 SPI 通信依赖 READY 线和固定帧长同步。
- 如需启用 88 字节 RESULT 输出，请先参考《H743 信号处理端 软件技术手册》第 6.2 节完成 SPI2 主机发送逻辑，再连接主控 F407。
