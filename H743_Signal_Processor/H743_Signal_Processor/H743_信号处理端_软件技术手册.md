# H743 信号处理端 软件技术手册

> 适用工程：`${workspaceFolder}`（或仓库内的 `H743_Signal_Processor/H743_Signal_Processor`）  
> 主控：STM32H743ZIT6  
> 输入：STM32F407 采集端通过 SPI1 上传的 4096 点 AD9226 原始码  
> 输出：同一 SPI1 全双工帧的 SET_FS 命令槽；USART1 诊断打印  
> 文档版本：2026-08-01（对应 `Firmware_H743/Core/Src/main.c`、`processor_app.c`、`spi_links.c` 及 `Algorithm/` 当前实现）

---

## 1. 文档说明

本文档从 H743 信号处理端软件角度描述数据流、算法流程、通信协议、编译/烧录和调测方法。阅读对象包括维护 H743 固件、理解 FFT/CZT/联合拟合参数估计流程、以及把 H743 接入 F407 采集/主控系统的开发者。

**注意**：当前 `Firmware_H743` 已经实现的物理链路只有 **SPI1 全双工 + USART1 诊断**；`Protocol/` 目录下的 88 字节 RESULT 协议已经完整编码并通过主机测试，但 **尚未在固件 main 循环中通过 SPI2 实际发送**。

## 2. 系统架构与数据流

### 2.1 总体框图

```text
                    ┌──────────────────────────────────────────┐
信号源 ──▶ AD9226 ──┤  F407 采集端                              │
                    │  TIM1_PE9 采样时钟 / DMA 采集 4096 点      │
                    │  SPI1 主机 (PA5/PA6/PA7)                  │
                    └──────┬───────────────────────┬───────────┘
                           │ MOSI(PA7)  样本 8192B │ MISO(PA6) 读 SET_FS
                           │ 全双工 8208B 帧        │ 16B 命令槽
                    ┌──────┴───────────────────────┴───────────┐
                    │  H743 信号处理端                          │
                    │  SPI1 从机 (PA5/PA6/PA7)                  │
                    │  PD0 = ACQ_READY 输出                     │
                    │  PD1 = MAIN_READY 输入（预留）             │
                    │  PA9/PA10 = USART1 诊断 115200             │
                    │  运行 SignalAnalyzer_Process()            │
                    └──────────────────────────────────────────┘
```

## 3. 硬件配置

### 3.1 时钟

- 外部晶振：HSE 25 MHz（PH0/PH1）。
- PLL1：M=5，N=192，P=2 ⇒ SYSCLK = 480 MHz。
- AHB 分频 4 ⇒ HCLK = 120 MHz。
- APB1/APB2 分频 2 ⇒ PCLK1/PCLK2 = 60 MHz。

### 3.2 引脚定义（来自 `H743_Signal_Processor.ioc` + `main.c`）

| H743 引脚 | 功能 | 方向/模式 | 连接对象 |
|---|---|---|---|
| PH0/PH1 | HSE 25 MHz | 晶振 | 25 MHz 无源晶振 |
| PA5 | SPI1_SCK | 从机输入 | F407 PA5 SPI1_SCK |
| PA6 | SPI1_MISO | 从机输出 | F407 PA6 SPI1_MISO |
| PA7 | SPI1_MOSI | 从机输入 | F407 PA7 SPI1_MOSI |
| PD0 | ACQ_READY | 推挽输出 | F407 PA4 H7_READY |
| PD1 | MAIN_READY | 下拉输入 | 主控 F407 预留 READY |
| PB13 | SPI2_SCK | 主机输出（预留） | 主控 F407 SPI2_SCK |
| PB15 | SPI2_MOSI | 主机输出（预留） | 主控 F407 SPI2_MOSI |

## 4. SPI1 全双工帧格式

### 4.1 物理层

| 项目 | 值 |
|---|---|
| H743 角色 | SPI1 从机 |
| 采集 F407 角色 | SPI1 主机 |
| 模式 | Mode 0（CPOL=0, CPHA=0） |
| 数据宽度 | 8 bit |
| 位序 | MSB first |
| NSS | 软件 NSS，无物理 CS |
| 流控 | PD0 ACQ_READY（H743 输出，F407 输入） |
| 帧长度 | 8208 字节 |

### 4.2 帧布局

```text
[0 .. 15]   = 16 B 命令槽占位（F407 -> H743，H743 忽略其内容）
[16 .. 8207] = 4096 × 2 B 样本，uint16_t 小端，低 12 位有效
```

H743 在 MISO 上同步返回 8208 字节：

```text
[0 .. 15]   = 16 B SET_FS 命令槽（H743 -> F407）
[16 .. 8207] = 8192 B 占位（全 0）
```

### 4.3 READY 握手时序

1. H743 挂载 `HAL_SPI_TransmitReceive_DMA(rx=8208, tx=8208)` 后，延迟 1 ms 拉高 PD0 ACQ_READY。
2. F407 检测到 ACQ_READY 高电平后开始发 SCK，全双工交换 8208 B。
3. DMA 完成中断里 H743 立即拉低 ACQ_READY，主循环进入算法处理。
4. 算法处理完成后回到步骤 1，MISO 中的 SET_FS 命令已经更新为下一帧采样率建议。

### 4.4 SET_FS 命令槽（16 字节）

| 偏移 | 长度 | 字段 | 说明 |
|---|---|---|---|
| 0 | 2 | magic | `0xA55A` 小端 |
| 2 | 1 | type | `0x01` |
| 3 | 1 | flags | bit0有效、bit1削顶恢复、bit2~4页号、bit5~7模型代号 |
| 4 | 4 | requested_fs_Hz | 建议下一帧采样率，5000~20000000 Hz |
| 8 | 2 | crc16 | CRC-16/CCITT-FALSE，覆盖偏移 0~7 |
| 10 | 6 | page_payload | 五页测量模型，显式小端 |

CRC 参数：poly=`0x1021`，init=`0xFFFF`，refin=false，refout=false，xorout=`0`。
页0为`f0:u32 + Upp_mV:u16`；页1为`Urms_mV:u16 + 分量数 + 状态 + quality + 0`；
页2~4分别为`阶次:u8 + 峰值幅度mV:u16 + 相位Q15:i16 + valid:u8`。五页
必须属于同一模型代号，F407组齐后才原子发布。

### 4.5 实际采样率换算

```text
divider  = floor(168000000 / requested_fs_Hz)
actualFs = 168000000 / divider
```

采集端 TIM1 的 `ARR = divider - 1`，与本公式等价。算法处理下一帧时使用 `actualFs`。

## 5. 信号处理算法流程

### 5.1 总览

`SignalAnalyzer_Process()` 按以下顺序执行：

```text
SignalPreprocess_Run
    ↓ 检查2048下限平台、生成有效掩码、标定到BNC伏特
SpectrumDetect_Find
    ↓ 4096 点 RFFT、Hann 窗、局部峰值、中位数噪声底
CztZoom_Refine（对每个候选）
    ↓ 129 点局部 CZT、log-power 峰顶插值
HarmonicModel_Select
    ↓ 选最多 3 个期望谐波 + 1 个高频干扰
OrthogonalFit_Run / ClippedHarmonicRecovery_Select
    ↓ 全样本或未削顶样本法方程，筛除削顶伪谐波并检查平台不等式
SignalMetrics_Populate
    ↓ 8192 相位点重构 Upp，解析 Urms
返回 SignalResult
```

### 5.2 预处理 `signal_preprocess.c`

- 12 位掩码：`code = samples[i] & 0x0FFF`。
- 零码：`AD9226_ZERO_CODE = 2055`。
- ADC标定：`Vadc = (code - 2055) * 0.005236 V`；板上交流增益为2，算法输出
  BNC口径：`Vbnc = Vadc / 2`。
- 计算直流均值并去除，得到交流样本。
- 统计交流能量 `ac_energy_V2`、端点码数量 `rail_code_count`、高 4 位异常数量 `high_bit_count`。

硬端点和下限平台分别处理：

```c
if (high_bit_count != 0 || rail_code_count * 100 > 4096)
    status = SIGNAL_STATUS_CLIPPED;
```

固定1.50 V偏置时，若原始码在2048~2050形成平台且没有更低码，低于2053的
点不进入拟合；有效样本不足25%或模型残差/平台约束不通过时仍返回CLIPPED。

### 5.3 频谱候选检测 `spectrum_detect.c`

- 对 4096 点交流样本加 Hann 窗。
- 调用 `SignalFft_Forward4096()` 做基-2 复数 FFT（非归一化）。
- 计算单边功率谱：`|X[k]|² / 4096²`。
- 在 `[minimum_frequency, nyquist]` 范围内找局部峰值。
- 噪声底取非峰值点的**中位数**。
- 门限：
  - 最低功率 `1e-9`；
  - 最小 SNR 12 dB（`SIGNAL_SPECTRUM_MIN_SNR_DB`）；
  - 动态范围 30 dB（`SIGNAL_SPECTRUM_DYNAMIC_RANGE_DB`）。
- 相邻峰值去重半径 2 个 bin。
- 返回最多 8 个候选，按频率排序。

### 5.4 CZT 细化 `czt_zoom.c`

对每个候选：

- 以 coarse bin 为中心，取 ±2 bin 的窄带。
- 129 点等间隔扫描；对每一点用递归复相量计算功率。
- 用 Hann 窗加窗后的样本参与 CZT。
- 取 log-power 峰顶及其左右两点做抛物线插值，得到亚 bin 精度频率。
- 结果频率被规范化到 10 kHz~500 kHz 工作带边缘。

### 5.5 谐波模型选择 `harmonic_model.c`

- 不直接把最强峰当基波。
- 在期望频段 10 kHz~500 kHz 内搜索满足谐波关系的组合。
- 候选组合：1 个基波；基波 + 1 个整数倍谐波；基波 + 2 个不同整数倍谐波。
- 评分：优先选谐波数量多 → 谐波误差小 → 总功率大 → 基频低。
- 保留最多 3 个期望分量（`desired=1`）。
- 若存在 ≥1 MHz 的高频干扰，作为额外非期望列（`desired=0`）加入模型，但最多 4 个 tone。

### 5.6 正交联合拟合 `orthogonal_fit.c`

- 以每个 tone 的 cos、sin 以及 DC 为基函数，建立法方程 `AᵀA·x = Aᵀb`。
- 双精度浮点、部分主元消元求解。
- 枢轴比 `< 1e-10` 视为病态，返回 `SIGNAL_STATUS_ILL_CONDITIONED`。
- 由 cos/sin 系数计算峰值幅度 `A = √(a²+b²)` 和相位 `φ = atan2(-b, a)`，并归一化到 `[-π, π)`。
- 计算残差 RMS 和 SNR：`SNR = 10·log10(signal_power / residual_power)`。

### 5.7 指标计算 `signal_metrics.c`

- 只使用 `desired=1` 的谐波分量。
- 验证各分量频率与基频的整数倍关系（误差 ≤1 kHz）。
- 用 8192 个相位点重构信号，搜索最大/最小值得到 `Upp`。
- 真有效值：`Urms = √(Σ A_i² / 2)`。

### 5.8 状态码

| 状态码 | 含义 | 触发条件 |
|---|---|---|
| `VALID` | 正常 | 全部通过 |
| `BAD_ARGUMENT` | 参数错误 | 空指针、采样率越界 |
| `CLIPPED` | 削顶/数据异常 | 高位异常或端点码过多 |
| `NO_SIGNAL` | 无信号 | 交流能量 ≤0 或没有候选 |
| `MODEL_INVALID` | 模型不合法 | 选模失败或指标收集失败 |
| `ILL_CONDITIONED` | 病态矩阵 | 枢轴比过低 |
| `SAMPLE_RATE_UNSAFE` | 采样率风险 | Fs ≤1 MHz 或高频干扰且 Fs<10 MHz |

## 7. 应用状态机 `processor_app.c`

```text
ARM_FRAME ──StartFrameExchange──▶ WAIT_FRAME
WAIT_FRAME ──DMA complete──▶ PROCESS_FRAME
PROCESS_FRAME ──SignalAnalyzer_Process + Encode SET_FS──▶ ARM_FRAME
```

- 默认首帧请求采样率：`2 048 780 Hz`（对应 168 MHz / 82 ≈ 2.04878 MHz）。
- 算法返回 `recommended_sample_rate_Hz` 在有效范围内时，使用该值作为下一帧请求；否则重发上一次请求值。
- 每次处理后把完整`SignalResult`交给五页pager；一轮0~4页始终来自同一快照，
  新结果只在下一轮页0切换。
- 出错时调用 `SPI_Links_AbortAll()`，1 ms 后重试。

## 10. 故障排查

| 现象 | 可能原因 | 排查/处理 |
|---|---|---|
| `[H7] rx=0` 不增长 | F407 未发时钟、READY 未拉高、SPI 接线反 | 检查 PA5/PA6/PA7、PD0→F4 PA4、共地；用示波器看 SCK |
| `hal_err` 非 0 | SPI 从机 DMA overrun、模式错 | 确认 F4 为 Mode 0 MSB first、帧长 8208 B |
| `sig=2 CLIPPED` | 输入幅度过大或高 4 位异常 | 降低信号幅度，检查 AD9226 OTR |
| `sig=3 NO_SIGNAL` | 输入幅度过小、频率带外 | 确认信号在 10 kHz~500 kHz，Vpp > 几十 mV |
| `sig=4 MODEL_INVALID` | 信号不是谐波结构 | 对多音非谐波信号预期行为；检查候选峰 |
| `sig=5 ILL_CONDITIONED` | 频率太接近或样本数不足 | 检查 Fs 与信号频率比 |
| `sig=6 SAMPLE_RATE_UNSAFE` | Fs ≤1 MHz 或存在高频干扰 | 提高采样率到 ≥10 MHz |
| 基频/谐波显示异常 | H743 与 F4 的 Fs 公式不一致 | 核对 `actualFs = 168M / floor(168M/req)` |
| RESULT 协议未发出 | SPI2 未初始化 | 按第 6.2 节补充 SPI2 主机发送 |
