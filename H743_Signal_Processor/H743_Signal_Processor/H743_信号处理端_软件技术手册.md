# H743 信号处理端软件技术手册

## 接收和调度

`Firmware_H743/Core/Src/spi_links.c` 管理 SPI1 双向 DMA 与 `ACQ_READY`。`processor_app.c` 在启动、等待及处理一帧三个状态间转换，校验样本帧的长度、协议字段及 CRC。分析使用帧头中的采样分频值，回传结果携带同轮测量的请求代号和分析采样率。

## 分析与回传

固件调用 `SignalAnalyzer_ProcessCalibrated()`。算法按输入量程与波形质量选择正常拟合或削顶恢复路径，识别基频和最多三个有效正弦分量（包含基波）。幅度指仪器输入端各正弦分量的峰值。`signal_metrics.c` 使用各分量的幅度和相位计算合成波形的峰峰值，以各正弦分量的功率之和计算交流有效值。正常测量根据 `frontend_response.h` 的频率节点插值，修正各分量幅度后再计算精度相关输出。

模型与采样率请求由 `h743_measurement_pages.c` 分页装入 SPI1 回传槽。新一轮开始时用请求代号区分会话。显示内容由 F407 根据完整模型生成。详细字节定义见 [SPI1 通信协议](docs/COMMUNICATION_PROTOCOL.md)。

## 调试和验证

H743 调试口为 USART1（PA9 TX、PA10 RX），115200 baud、8N1。构建、烧录及主机测试命令见[仓库说明](../../README.md)。主机测试覆盖数值分析、频响插值和协议；板间握手、电压与时序在实机上验证。
