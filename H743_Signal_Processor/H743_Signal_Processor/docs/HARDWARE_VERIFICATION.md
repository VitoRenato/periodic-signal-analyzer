# 双板实机验证

## 采集

1. 核对 D0～D11、PE9 采样时钟和模块供电。接入已知频率与幅度的正弦输入，在模块端测参考电压。
2. 通过 F407 调试串口发送 `c`，保存完整的 4096 点原始码和 `fs_hz`、`arr`、`psc`。核对数字位计数、码值范围及波形。需要确认采样时序时，用示波器直接测 CLKIN。

## 板间交换

用逻辑分析仪同时观测 PD0/PA4、SCK、MOSI、MISO。核对 READY 先于交换、每次交换 8214 字节、两方向前 22 字节的布局，以及应用采样率变更后下一采集头的实际分频。解析字段时使用 [SPI1 通信协议](COMMUNICATION_PROTOCOL.md)。

## 测量和显示

使用单频和规定的谐波叠加信号，记录仪器端参考值、原始码、屏显结果和测量耗时。各谱线幅度按峰值比较，合成信号单独比较 Vpp 与交流 Vrms。记录所用固件版本、信号源负载、频率、偏置和参考仪器。以重新测量获得新结果，短按 PA15 检查 1／3 周期切换。
