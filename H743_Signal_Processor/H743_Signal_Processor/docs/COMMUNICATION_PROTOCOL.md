# F407 ↔ H743 SPI1 通信协议

双板使用同一个 SPI1 全双工事务交换采样与测量结果。F407 是主机，H743 是从机，Mode 0、8 位、MSB first、软件 NSS；多字节字段按小端排列。F407 以 5.25 MHz 发送，每次交换 **8214 字节**。H743 挂载 DMA 后通过 PD0 通知 F407 的 PA4；F407 在 READY 有效时开始交换。

## MOSI：采集头和样本

前 22 字节是采集帧头，随后是 4096 个小端 `uint16_t`，每个样本的有效位为 bit0～bit11。

| 字节偏移 | 类型 | 含义 |
|---|---|---|
| 0～1 | `uint16_t` | `0x5AA5` |
| 2 | `uint8_t` | 版本 `3` |
| 3 | `uint8_t` | bit0 上电标记，bit1 重测标记 |
| 4～5 | `uint16_t` | 采样时 TIM1 分频值 `ARR + 1`，采样率为 `168000000 / 分频值` |
| 6～9 | `uint32_t` | 采集帧序号 |
| 10～13 | `uint32_t` | 8192 字节样本的 CRC-32/ISO-HDLC |
| 14～15 | `uint16_t` | 字节 0～13、16～17 的 CRC-16/CCITT-FALSE |
| 16～17 | `uint16_t` | 测量请求代号，同轮保持不变 |
| 18～21 | — | 保留，置零 |
| 22～8213 | `uint16_t[4096]` | AD9226 原始码 |

## MISO：控制槽与模型页

H743 在交换开始前预装槽内数据。前 22 字节包含采样率请求和模型的一页，其余为填充字节。模型产生之前，控制槽可只携带采样率请求。

| 字节偏移 | 类型 | 含义 |
|---|---|---|
| 0～1 | `uint16_t` | `0xA55A` |
| 2 | `uint8_t` | 类型 `0x81` |
| 3 | `uint8_t` | bit0 模型有效，bit1 削顶恢复，bit2～4 页号，bit5～6 模型 ID，bit7 会话起始 |
| 4～7 | `uint32_t` | 请求采样率（Hz，5 kHz～20 MHz） |
| 8～9 | `uint16_t` | 字节 0～7、10～21 的 CRC-16/CCITT-FALSE |
| 10～11 | `uint16_t` | 回显测量请求代号 |
| 12～15 | `uint32_t` | 计算本模型所用的采样率（Hz） |
| 16～21 | `uint8_t[6]` | 单页载荷 |

| 页号 | 6 字节载荷，按顺序 |
|---|---|
| 0 | 基频 `uint32_t`（Hz），模型 Vpp `uint16_t`（mV） |
| 1 | 模型交流 Vrms `uint16_t`（mV），分量数、状态、质量标志各 1 字节，最后 1 字节保留 |
| 2～4 | 谐波阶次 1 字节，分量峰值 `uint16_t`（mV），相位 `int16_t`（弧度 × 32768/π 后量化），有效标志 1 字节；空分量页置零 |

H743 在页 0 切换待发模型，固定按页 0～4 发送。F407 按当前请求代号、会话起始标志、模型 ID、采样率和页序组装整组数据，完成后校验模型；常规显示锁定需要连续两份独立且一致的完整模型。

协议实现：F407 端 `USER/protocol/acq_frame_tx.c`、`h743_measurement_rx.c`；H743 端 `Protocol/Src/acq_frame_header.c`、`h743_set_fs_protocol.c`、`h743_measurement_pages.c`。物理连接见 [H743 接线指南](../H743_信号处理端_接线指南.md)。
