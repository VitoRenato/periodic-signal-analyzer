## 一、直接可用的两个参数

| 参数 | 数值 | 单位 | 来源 |
|------|------|------|------|
| `zero_code` | **2055** | code | SMA 输入 0V(中心短路到外壳)时,4096 点均值 |
| `scale_uV_per_code` | **5236** | µV / code | 1V DC 输入导致 code 偏移 191,计算得 1 000 000 / 191 |

---

## 二、H7 使用的转换公式

```c
/* ADC code → 外部 SMA 输入瞬时电压(单位 µV,以 0V 为中心) */
input_uV = (adc_code - zero_code) * scale_uV_per_code;
input_uV = (adc_code - 2055) * 5236;
```

### 示例

| adc_code | input_uV | 说明 |
|----------|----------|------|
| 2055 | 0 µV | 零点(0V 输入) |
| 2246 | +1 000 000 µV = +1.000 V | 1V DC 实测点 |
| 4095 | +10 681 000 µV ≈ +10.68 V | 正满量程估算 |
| 0 | -10 759 000 µV ≈ -10.76 V | 负满量程估算 |

## 三、实测数据记录

| 输入条件 | 实测 mean | 备注 |
|----------|-----------|------|
| SMA 短路(0V) | 2055 (0x807) | 零点,作为 zero_code |
| SMA 接 +1.000V DC | 2246 (0x8C6) | 相对零点偏移 +191 codes |

计算:

```
scale_uV_per_code = 1 000 000 µV / 191 codes = 5235.6 µV/code
                  ≈ 5236 µV/code
```

---

## 四、满量程估算

按当前 scale 反推:

- 正满量程: `(4095 - 2055) × 5236 µV = 10 681 000 µV ≈ +10.68 V`
- 负满量程: `(0 - 2055) × 5236 µV = -10 759 000 µV ≈ -10.76 V`
- **总输入范围 ≈ 21.4 V p-p**

> 注:FPGA 参考代码注释写 `-10V ~ +10V : 码值 0~4095`,与本次实测基本吻合。说明该模块前级实际按 ±10V 量程设计,与部分文档里写的 4.2V p-p 不一致。**以本次实测为准**。

## 五、应用范围

| H7 需要 | 公式 |
|---------|------|
| 瞬时电压 | `u[n] = (adc_code[n] - 2055) × 5236` |
| Upp | `max(u[n]) - min(u[n])` |
| Urms | `sqrt(mean(u[n]^2))` |
| FFT 幅值 | 对 `u[n]` 做 FFT,`abs(X[k])` 单位为 µV |

## 六、不确定度与改进建议

1. **本次标定仅用了 1 个非零点(1V DC)**。若 H7 对 ±5 mV 指标要求严格,建议补充:
   - 用精密电压源(或校准过的函数发生器)做 **2 点标定**(如 0V 和 +2V)
   - 或做 **多点线性拟合**(0V, ±1V, ±2V, ±5V),消除前端非线性误差

2. `zero_code` 可能随温度/时间漂移数 LSB,正式测试前建议每次上电后用 SMA 短路重新测一次零点。

3. 如果后续发现 1V DC 实测偏移不是 191,应重新计算 scale 并更新本文档。

## 七、H7 快速 copy 区

```c
#define AD9226_ZERO_CODE        2055
#define AD9226_SCALE_UV_PER_CODE 5236

static inline int32_t ad9226_code_to_uV(uint16_t code)
{
    return ((int32_t)code - AD9226_ZERO_CODE) * AD9226_SCALE_UV_PER_CODE;
}
```
