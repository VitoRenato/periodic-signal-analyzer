## 当前接口与证据边界

当前发布架构为 STM32F407ZGT6 + STM32H743ZIT6。采集端 F407 始终是 SPI1
主机，并以一个 **8208 B 全双工帧**交换数据：16 B 命令槽 + 8192 B 样本；
MISO 在同一传输内返回命令槽。不存在当前发布接口中的“先传 8192 B、再以
独立时钟读取 10 B”阶段，也不能把快照中的 SPI2 叙述理解为已启用的当前链路。
唯一的规范性协议是 [`../COMMUNICATION_PROTOCOL.md`](../COMMUNICATION_PROTOCOL.md)。

快照中的时钟、量程、示波器、串口、烧录及任何“通过”表述均为日期不明的历史
单点观察，未对当前二进制重新验证。原始 F407 串口日志、仪器型号、探头设置、
校准记录和物理接线照片均未随仓库发布；没有这些可核验来源，本清单不提供
`Flash verified`、时钟达标、精度或端到端物理验收结论。

等效采样工程不整体复制。对它的选取和排除结论已经固化在
[`../SPI_REFERENCE_AUDIT.md`](../SPI_REFERENCE_AUDIT.md)；该工程始终是只读参考，
不是本项目依赖。
