# STM32H743 信号参数估计技术路线

更新日期：2026-07-31  
目标芯片：STM32H743ZIT6  
外部晶振：25 MHz  
状态：设计已确认；公共接口和基础预处理已通过主机测试，完整算法和上板待完成

## 1. 项目范围与边界

本项目建立仓库内新的 `H743_Signal_Processor/H743_Signal_Processor`，替代原计划中的
`H723_Signal_Processor`，但不直接修改以下队友工程：

- 旧 F407 采集 SPI 主机工程（本地只读参考，未随仓库发布）
- 旧 F407 显示 SPI 从机工程（本地只读参考，未随仓库发布）
- 旧 H723 信号处理工程（本地只读参考，未随仓库发布）

系统当前分工：

```text
F407 + AD9226
  ├─ 采集4096点原始数据
  ├─ 向H743发送8192字节原始帧
  └─ 接收H743发出的SET_FS采样率命令
             ↓
STM32H743ZIT6
  ├─ 数据标定和质量检查
  ├─ RFFT全局搜索
  ├─ CZT局部精确测频
  ├─ 联合正交相关器精确估计幅相
  └─ 输出基频、Upp、真有效值和最多3个频谱分量
```

512 点波形和 256 点频谱只是显示端的压缩绘图数据。当前修改后，它们由
采集板和主控 F407 的等效采样/显示链路处理，不属于 H743 参数估计算法的
输入或输出。

本项目只负责 H743 数据计算部分。H743到主控F407的88字节结果协议已经在
`COMMUNICATION_PROTOCOL.md`中冻结，但协议源码和主控F407接收端尚未实现。
协议适配层不能侵入算法核心。

## 2. 已确认的采集端输入契约

权威依据：

- `references/F407_AD9226_TECHNICAL_MANUAL.md`
- `references/AD9226_CALIBRATION.md`

旧 F407 处理器原型中的 8220 字节带头、序号和 CRC32 的帧，不再是本 H743
项目的采集输入契约。当前 AD9226 采集端发送的是固定 8192 字节裸数据。

### 2.1 SPI采样帧

| 项目 | 当前约定 |
|---|---|
| 样本数 | 4096 |
| 单样本 | `uint16_t`，有效数据位为 bit0~bit11 |
| 总长度 | 8192 字节 |
| 字节序 | 每个样本低字节在前 |
| SPI模式 | Mode 0，8 bit，MSB first |
| SPI时钟 | 约 5.25 MHz |
| NSS/CS | 软件 NSS，无物理 CS |
| 帧头/序号/CRC | 无 |

H743重组方式：

```c
sample[i] = ((uint16_t)rx[2U * i + 1U] << 8)
          |  (uint16_t)rx[2U * i];
sample[i] &= 0x0FFFU;
```

### 2.2 READY握手

H743 READY 为推挽输出：

1. H743 启动8192字节SPI1 RX DMA后拉高READY。
2. F407检测到READY高电平后发送固定长度帧。
3. H743 DMA收满后立即拉低READY，只在中断中置位“帧完成”事件。
4. H743完成算法后挂载10字节SPI1 TX DMA，再拉高READY。
5. F407作为SPI1主机发送10个dummy字节产生时钟，同时从MISO读取SET_FS。
6. H743发送完成后拉低READY；完成结果输出后重新挂载下一帧RX DMA。

F407等待 READY 的超时为 100 ms。中断中不运行 FFT、CZT 或矩阵求解。

### 2.3 动态采样率命令

F407 默认实际采样率为：

```text
Fs = 168 MHz / 82 = 2.048780 MHz
```

F407支持5 kHz~20 MHz动态采样率。H743通过原SPI1的MISO返回固定10字节
`SET_FS`命令。采集F407保持SPI1主机，负责产生读取时钟；H743不切换主从：

| 偏移 | 字段 | 说明 |
|---:|---|---|
| 0~1 | magic | `0xA55A`，小端 `5A A5` |
| 2 | type | `0x01` |
| 3 | reserved | `0x00` |
| 4~7 | fs_hz | `uint32_t`小端 |
| 8~9 | crc16 | CRC16/CCITT-FALSE，小端 |

CRC参数：poly=`0x1021`，init=`0xFFFF`，不反射，xorout=`0`，覆盖前8字节。
该返回阶段继续使用SPI1的Mode 0、8 bit、MSB first和约5.25 MHz SCK。

H743必须保存“最近一次已实际应用的 Fs”，因为8192字节采样帧本身不包含
采样率。不能把请求值未经确认直接当作实际值；F407的TIM分频会造成取整。

## 3. AD9226标定

当前实测参数：

```c
#define AD9226_ZERO_CODE          2055
#define AD9226_SCALE_UV_PER_CODE  5236
```

转换公式：

```text
u[n] = ((raw[n] & 0x0FFF) - 2055) × 5236 µV
```

算法内部建议转成 `float32` 伏特，降低数值量级：

```text
x[n] = ((raw[n] & 0x0FFF) - 2055) × 0.005236 V
```

需要保留以下限制：

- 当前斜率只使用 0 V 和 +1 V 单点计算。
- 1 LSB约为5.236 mV，题目要求分量幅值误差不超过5 mV，标定误差已经和
  指标同量级。
- 正式验收前需要至少重新测零点，并优先做 `0、±1、±2、±5 V` 多点线性
  标定。
- 算法拟合不能消除模拟前端增益误差、非线性和温漂。

## 4. 测量目标

对“基频加一至两个谐波”的周期信号，计算：

- 基频 `f0`；
- 峰峰值 `Upp`；
- 真有效值 `Urms`；
- 最多3个有效频谱分量的频率、峰值幅度和相位；
- 拟合残差、有效性状态和当前采样率。

目标频率范围按现有需求保留为10 kHz~500 kHz。若最终题面把部分模式限制
在200 kHz，应通过配置缩小搜索范围，不另写一套算法。

频谱“幅度”统一定义为正弦峰值：

```text
x_i(t) = A_i cos(2πf_i t + φ_i)
```

不要把峰值、有效值和峰峰值混用。

## 5. 最终算法流水线

```text
4096点原始码
  → 掩码/饱和检查/标定/去ADC静态零点
  → Hann窗 + 4096点RFFT全频段候选搜索
  → 基频与整数谐波组合判定
  → 每个候选附近做局部CZT精确测频
  → 联合正交相关器求所有分量幅值和相位
  → 排除高频干扰分量
  → 用有效分量重构周期波形
  → 计算f0、Upp、Urms和最多3个频谱分量
```

### 5.1 数据预处理

1. 所有输入先执行 `& 0x0FFF`。
2. 统计0码、4095码和越界比例，用于判断削顶或链路异常。
3. 按标定参数转成伏特。
4. 估计并去除剩余直流项，但在后续联合拟合中仍保留一个常数列，吸收残余
   零偏。
5. 用Hann窗数据做频谱检测；最终幅相拟合必须回到未加窗的标定数据。

### 5.2 RFFT全局搜索

- 使用4096点实数FFT。
- 跳过DC和极低频漂移区。
- 在配置的有效带宽内寻找局部峰值。
- 用噪声底的中位数或稳健均值设置门限，不能只取固定幅值门限。
- 保留比最终3个更多的候选，例如6~8个，供谐波组合和干扰判定。
- 三点二次插值只作为粗定位增强或CZT降级方案，不作为最终测频结果。

粗频率分辨率：

```text
Δf_fft = Fs / 4096
```

500 Hz测频要求不是简单要求FFT频点间隔小于500 Hz。CZT和参数拟合可以在
频点之间估计，但必须用仿真和实测证明误差。

### 5.3 基频和谐波关系判定

不能简单把最大峰当作基频，因为谐波幅度可能大于基波。应枚举候选基频，
检查其他峰是否接近其整数倍，并综合：

- 倍频关系误差；
- 峰值信噪比；
- 联合拟合后的残差；
- 有效频带限制；
- 分量数量不超过3。

最终选择残差较小、谐波关系合理的模型。谐波阶数的最大搜索范围应作为
配置项，待最终题面确认后锁定。

### 5.4 局部CZT精确测频

CZT不负责全频段盲搜，只在RFFT候选附近放大：

- 初始中心：RFFT峰值或三点插值结果；
- 搜索宽度：约为粗频点左右各1~2个FFT bin；
- 局部频率步进：建议不大于100 Hz，再做峰顶插值；
- 对每个候选分别运行，最多处理少量候选。

资料目录里的旧CZT源码不能直接复制：

- 固定为2048点，与当前4096点不一致；
- 存在边界和幅值归一化问题；
- 其复数结果不能直接作为可信相位。

H743版本应重新实现并通过单音、多音、非整周期和频带边缘测试。可以采用
Bluestein卷积形式并复用CMSIS-DSP FFT，也可以先实现直接局部CZT作为正确
性参考，再优化性能。

### 5.5 联合正交相关器

正交相关器正式放在CZT之后。CZT给出频率，联合正交相关器给出最终幅值和
相位。

建立模型：

```text
x[n] = c
     + Σ(a_i cos(2πf_i n/Fs) + b_i sin(2πf_i n/Fs))
     + e[n]
```

普通单频正交相关直接分别求I/Q，只在整数周期、单音或完全正交时严格成立。
本任务是非整周期、多分量信号，各参考列之间有互相关，独立I/Q会产生幅值
串扰。

因此构造参考矩阵 `Φ` 并联合求解：

```text
G = ΦᵀΦ
r = Φᵀx
Gθ = r
```

这就是“多频率正交相关 + Gram矩阵串扰修正”。当参考列完全正交时，会
自然退化成普通正交相关器。

最多3个有效分量，再按需要加入1个高频干扰分量，因此矩阵规模很小：

```text
1个DC列 + 每个频率2列
K=3时为7个参数
K=4时为9个参数
```

建议：

- 原始数据和正余弦参考使用 `float32`；
- 点积累加和小矩阵求解优先使用 `float64`，矩阵很小，H743可承受；
- 使用QR或带主元分解；若使用正规方程，必须检查条件数/主元；
- 禁止运行时 `malloc`；
- 记录残差RMS、SNR估计和矩阵病态状态。

按上述余弦加正弦模型：

```text
A_i = sqrt(a_i² + b_i²)
φ_i = atan2(-b_i, a_i)
```

相位符号必须用合成信号单元测试固定，不能凭旧源码确定。

### 5.6 干扰识别与抗混叠边界

干扰模式可能出现幅值约200 mV、频率不低于1 MHz的单音。算法可做：

1. 在高频区检测该候选；
2. 把它作为额外正弦列加入联合拟合；
3. 输出结果时剔除该分量；
4. 只用有效频带内的最多3个分量重构目标波形。

但数字算法不能恢复已经混叠的信息。默认 `Fs=2.048780 MHz` 的Nyquist频率
约为1.024390 MHz，高于Nyquist的干扰可能折叠进0~500 kHz有效带，此时仅凭
一帧数据无法判断它原来是高频干扰还是有效信号。

因此：

- 检测干扰时优先请求较高采样率，例如10 MHz或20 MHz；
- 若干扰频率没有上限，即使20 MHz也不能保证完全无混叠，仍需要模拟
  抗混叠滤波器或明确干扰上限；
- 动态降低Fs虽然能增加低频信号的观测周期数，但必须先确认不会把高频
  干扰混叠进有效带；
- 采样率策略必须输出状态，不能悄悄改变Fs后仍沿用旧Fs计算。

建议先采用稳定的高采样率完成正确性版本，再根据实测运行时间决定是否加入
“高采样率侦察帧 + 自适应测量帧”的双阶段策略。

## 6. Upp和真有效值

### 6.1 重构目标信号

使用联合拟合得到的有效分量重构：

```text
x_valid(t) = Σ A_i cos(2πf_i t + φ_i)
```

ADC零偏和判定为干扰的分量不计入目标波形。

### 6.2 Upp

不能直接使用4096个采样点的最大值减最小值，因为采样时刻可能错过真正
峰值，而且多谐波峰值取决于相位。

在一个基频周期内对拟合模型做高密度重构，例如4096或8192个相位点：

```text
Upp = max(x_valid) - min(x_valid)
```

### 6.3 真有效值

如果所有有效分量已经确认是基频的整数谐波，在整基频周期上：

```text
Urms = sqrt(Σ A_i² / 2)
```

也可对高密度重构波形做平方平均，作为统一实现和交叉检查：

```text
Urms = sqrt(mean(x_valid²))
```

此处输出的是去除采集零偏后的周期信号真有效值，不把AD9226中点码对应的
直流偏置计入结果。

## 7. 建议的算法接口

算法核心不包含HAL、SPI句柄或DMA操作：

```c
#define SIGNAL_FRAME_SAMPLES      4096U
#define SIGNAL_MAX_COMPONENTS        3U

typedef enum
{
    SIGNAL_STATUS_VALID = 0,
    SIGNAL_STATUS_BAD_ARGUMENT,
    SIGNAL_STATUS_CLIPPED,
    SIGNAL_STATUS_NO_SIGNAL,
    SIGNAL_STATUS_MODEL_INVALID,
    SIGNAL_STATUS_ILL_CONDITIONED,
    SIGNAL_STATUS_SAMPLE_RATE_UNSAFE
} SignalStatus;

typedef struct
{
    float frequency_Hz;
    float amplitude_peak_V;
    float phase_rad;
} SignalComponent;

typedef struct
{
    SignalStatus status;
    uint32_t sample_rate_Hz;
    float fundamental_Hz;
    float upp_V;
    float urms_V;
    float residual_rms_V;
    float snr_dB;
    uint8_t component_count;
    SignalComponent component[SIGNAL_MAX_COMPONENTS];
    uint32_t recommended_sample_rate_Hz;
} SignalResult;

SignalStatus SignalAnalyzer_Process(
    const uint16_t samples[SIGNAL_FRAME_SAMPLES],
    uint32_t sample_rate_Hz,
    SignalResult *result);
```

最终与主控F407连接时，仅由协议适配层把该结果转换为
`COMMUNICATION_PROTOCOL.md`规定的mHz、µV和毫度整数；不要修改算法内部
的Hz、V和rad单位。SET_FS通过SPI1的MISO分时返回，H743的SPI2专用于向
主控F407发送88字节RESULT。两条总线都保持固定主从角色。

## 8. H743工程和内存安排

25 MHz HSE是已知硬件条件，但系统时钟、PLL参数和电源等级必须结合实际板卡
及CubeMX重新确认，不能直接照搬旧H723工程。

建议目录：

```text
H743_Signal_Processor/
  Firmware_H743/
  Algorithm/
    Inc/
      signal_analyzer.h
      czt_zoom.h
      orthogonal_fit.h
      signal_metrics.h
    Src/
      signal_analyzer.c
      czt_zoom.c
      orthogonal_fit.c
      signal_metrics.c
  Platform/
    spi_acq_adapter.c
    sample_rate_command.c
    result_link.c
  Protocol/
    Inc/
    Src/
  tests/
  docs/
```

内存原则：

- 8192字节SPI RX DMA缓冲区放RAM_D2，32字节对齐，并配置为不可缓存；
  或严格执行D-Cache invalidate流程。
- H743普通DTCM不能被DMA1/2访问，禁止把SPI DMA缓冲区放进DTCM。
- FFT/CZT大工作区放AXI SRAM或其他容量合适的RAM。
- 小矩阵、状态和频繁访问的标量可放DTCM。
- 禁止大型自动数组和运行时动态分配。
- 中断只处理READY、电平、DMA事件和错误状态，算法在主循环运行。

## 10. 测试与验收矩阵

主机合成测试至少覆盖：

- 单音、基频+一个谐波、基频+两个谐波；
- 基波不是最大分量；
- 随机相位和接近最不利峰值相位；
- 频率落在FFT频点、半频点和频点附近任意位置；
- 10 kHz、500 kHz及边界附近；
- 不同Fs和动态Fs切换；
- 直流偏置、白噪声、量化、零点漂移；
- 0码/4095码削顶；
- 约1 MHz、200 mV干扰以及混叠案例；
- 两候选非常接近导致矩阵病态；
- 无信号、纯噪声和无效参数。

验收时分别统计：

- 基频绝对误差；
- 每个分量峰值幅度误差；
- Upp误差；
- Urms误差；
- 分量数和谐波阶次识别正确率；
- 干扰剔除结果；
- 残差与状态码；
- H743每阶段周期数、总耗时、栈和RAM占用。

最终指标需使用经过多点标定的实测电压验证。旧资料里的演示数字不能作为
本系统的验收证据。

## 11. 当前明确不采用的做法

- 不把最大FFT峰直接当基频。
- 不用FFT频点幅度直接作为最终幅值。
- 不用普通单频独立I/Q代替联合正交拟合。
- 不用采样点最大减最小直接作为最终Upp。
- 不把CZT单独当成完整参数估计算法。
- 不原样复制旧2048点CZT、旧正交测相、旧RMS或平顶窗源码。
- 不在H743算法中生成512点波形和256点频谱绘图数据。
- 不以编译成功代替硬件验证。
