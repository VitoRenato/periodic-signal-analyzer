# 淘晶驰屏幕工程

`TJCscr.HMI` 是屏幕源工程，用淘晶驰串口屏上位机打开，核对屏幕型号后编译、下载。本目录保存屏幕源工程。

屏幕串口与 F407 的 USART2 连接，PA2 TX 接屏幕 RX，PA3 RX 接屏幕 TX，并共地。两端均使用 921600 baud、8N1，屏幕断电重启后也需保持相同波特率。

| 对象名 | 尺寸 | 固件绘图范围 |
|---|---|---|
| `page0` | 页面 | 固件启动时进入此页 |
| `s_wave` | 761×161 | 零线为 80，纵向范围为 8～152，三周期模式发送 761 点 |
| `s_fft` | 441×121 | 零幅值在底部 0，峰顶为 112，横向发送 441 点 |

网格为 40×40 像素，尺寸多出的 1 像素用于保留边界格线。单周期模式使用一个周期的模型采样点。屏幕上的波形由测量模型重建并归一化，不是原始 ADC 点值直接绘制。

对象名和显示配置见 [screen_config.h](../AD9226_driver3/AD9226_driver/USER/config/screen_config.h)，坐标转换见 [screen_view.c](../AD9226_driver3/AD9226_driver/USER/app/screen_view.c)。界面中的 `v01` 表示第一分量的峰值，不是输入峰峰值。

两个曲线控件均使用 `dir=0`。F407 在发送前按该平推方向排列像素，使屏上时间和频率从左到右递增。测量结果锁定后更新数值和曲线；PA15 短按切换周期时只重画时域曲线。

修改尺寸、对象名或方向后，需同步检查固件配置、显示渲染测试和实屏。主机检查入口为 `screen_view_tests` 和 `screen_curve_direction_tests`。
