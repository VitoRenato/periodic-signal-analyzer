# 原始码导出与标定

F407 以 16 位半字读取 GPIOF。PF0～PF11 对应 AD9226 的 D0～D11，帧整理时按 `0x0FFF` 掩码提取每个样本，得到 4096 个范围为 0～4095 的原始码。

## 导出

1. 连接 F407 的 USART1：PA9 为 TX，PA10 为 RX，共地。串口参数为 921600 baud、8N1、无硬件流控。
2. 发送 `c` 或 `C`，完整保存 `[CAL12 BEGIN]` 至 `[CAL12 END]`。开头记录 `seq`、`count`、`bits`、`fs_hz`、`arr`、`psc`、`min`、`max`、`pp` 和 `sum`。位计数按 bit0 至 bit11 排列，随后为 `index,code` 两列，索引 0～4095。`fs_hz` 由 TIM1 寄存器和 168 MHz 定时器时钟计算。
3. 导出帧不参与 H743 测量。导出后保持屏幕已有内容，连续二进制镜像关闭，自动连测暂停。再次发送 `c` 可重新采集；发送 `m` 或长按 PA15 恢复正常测量。

## 标定记录

固定信号源负载档位、接线、前端和采样设置。在仪器实际输入端用示波器记录频率、直流偏置与 Vpp，保存对应原始码。零交流点保持工作偏置和已定义的输入端接；增益点可用同一频率下两档未削顶的正弦输入。频响标定按频点重复，记录实际参考电压与测量结果。

`p` 输出当前帧摘要；正式标定使用 `c` 导出的 ADC 原始码。固件中的转换参数见 [H743 电压标定](../AD9226_标定参数_H7.md)。主机测试 `ad9226_raw_capture_tests` 直接编译生产采集驱动，检查原码范围、半字掩码与帧发布边界。
