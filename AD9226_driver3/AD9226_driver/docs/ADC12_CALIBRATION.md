本版本恢复生产 F407 固件的十二位原始采集。GPIOF 的 bit0 至 bit11 保持 DMA 采到的值，只清除与 ADC 无关的 bit12 至 bit15。不再展开低八位，不把均值移到 2055，不用软件平滑或重构代替原始码。引脚、采样时序、默认采样率和 H743 标定系数没有随本次修改调整。

标定使用 F407 的 USART1，PA9 为 TX，PA10 为 RX，921600 baud、8N1、关闭硬件流控。不要接到 TJC 屏的 USART2 或 H743 的调试串口。固件启动时应出现 [ADC12] raw capture enabled 提示。发送小写 c 或大写 C，固件导出一帧 4096 点的原始码；允许附加回车换行。完成后停止采集，再次发送 c 可重新取帧。已冻结或出现测量超时后也可请求新帧；若收到 CAL12 ERROR，请一并保留错误原文，不把它当作有效标定数据。

c 命令优先于后续 H743 帧交换，导出不依赖 H743 返回有效模型。它关闭连续二进制镜像，本帧不送 H743 分析，屏幕可能仍保留之前的结果。标定时以串口原始码为准，不拿屏幕现有电压作为参考。

完整保留从 [CAL12 BEGIN] 到 [CAL12 END] 的输出。开头含帧序号、4096 点计数、12 位标识、按当前 TIM1 ARR/PSC 与工程 168 MHz 定时器时钟计算的采样率、最小值、最大值、码值峰峰差和总和。fs_hz 是寄存器推导值，不是示波器实测值。随后给出 bit0 到 bit11 各自为一的样本数，再输出 index,code 两列 CSV，索引为 0 至 4095。不会在这个导出中应用旧电压系数。

先提供一帧无交流输入、保持实际使用偏置的原始码，同时说明偏置电压和接线状态；不要随意把模块的差分 ADC 引脚短接到地。然后用固定频率的正弦，在不削顶的条件下提供两个不同幅度的采样，例如题目范围内的 100 mVpp 与 250 mVpp。每组都说明频率、信号源幅值、50 Ω 或高阻输出设置、外部偏置，以及示波器在装置 BNC 入口测到的实际峰峰值。若没有示波器实测，也可以先发信号源设定值和完整采样，但只能据此做初步换算，不能声称完成绝对电压标定。

优先确认数据是否为正确的十二位输出，再拟合零点与增益。如果高位仍然异常、波形削顶、零点随输入漂移或不同幅度得到的比例不一致，应先查采集链路和前端，不以重新加回低八位恢复的方法掩盖问题。p 命令仅查看最近帧摘要，d 命令保留旧版调试格式及旧电压列，正式标定只使用 c 命令。

固件使用工程 Makefile。在仓库根目录运行 `make -C AD9226_driver3/AD9226_driver -B -j4` 完整构建 F407；确认探针和目标板后，可用 `make -C AD9226_driver3/AD9226_driver flash` 烧录。多个 ST-Link 同时连接时显式传入 `STLINK_SERIAL_F4`。本步骤只更新 F407，不需要同时烧录 H743。

新增 ad9226_raw_capture_tests 直接编译生产 Core/Src/ad9226.c，检查全部 0 至 4095 原码、带无关 GPIO 高四位的样本、完成前拒绝发布与重复 Finalize 的幂等性。HAL 和 DMA 在主机测试中为替身；这些检查证明软件保留了十二位数据，不证明实体 ADC 的引脚时序、精度或接线已经通过实机验收。旧低八位恢复器及其历史录波回归仅保留为历史算法测试，不再链接进生产 F407 固件。
