# F407 AD9226 采集端 接线指南

> 适用硬件：STM32F407ZGT6 核心板 + AD9226 V1.4 模块 + TJC 串口屏 + STM32H743（可选信号处理/控制）  
> 适用工程：`${workspaceFolder}`（在 VS Code 中打开 `AD9226_driver3/AD9226_driver`）  
> 文档版本：2026-08-01

> 发布边界（2026-08-04）：当前二板架构是 F407 + H743，二者以 SPI1 的 8208 B
> 全双工帧通信（16 B 命令槽 + 8192 B 样本）。旧 H723 名称、SPI2 方案、
> 仪器读数和“应/通过”等描述只用于历史追溯；它们不构成当前固件的接线授权、
> 物理验收或性能证明。当前通信契约以
> `H743_Signal_Processor/H743_Signal_Processor/docs/COMMUNICATION_PROTOCOL.md` 为准。

---

## 1. 接线总览

```text
                ┌─────────────┐
   信号源 ─────▶│ AD9226 V1.4 │────── PF0~PF11 (数据)  ─────▶ F407
   (SMA)        │   模块      │────── PE9        (时钟)  ─────▶ F407
                │             │────── PC12       (OTR)   ─────▶ F407 (可选)
                └─────────────┘      5V / GND           ─────▶ 电源

   F407 ──────── PA5/PA6/PA7 ────────────────▶ H743 SPI1 (全双工)
   F407 ──────── PA4 ────────────────────────▶ H743 READY (握手)
   F407 ──────── PA2/PA3 ────────────────────▶ TJC HMI 串口屏
   F407 ──────── PA9/PA10 ───────────────────▶ USB-TTL (调试)
   F407 ──────── PA13/PA14 ──────────────────▶ ST-Link SWD
   F407 ──────── PA15 ───────────────────────▶ 按键（周期切换）
```

## 2. 电源接线

### 2.1 F407 核心板供电

| 项目 | 要求 |
|------|------|
| 输入 | 5 V DC（USB 或外部稳压） |
| 板载 LDO | 3.3 V |
| GND | 与所有外设共地 |

### 2.2 AD9226 V1.4 模块供电

| 模块 P2 引脚 | 接法 | 说明 |
|--------------|------|------|
| Pin 1 / Pin 2 | **5 V** | AVDD 模拟电源 |
| Pin 3 / Pin 4 / Pin 19 / Pin 20 | **GND** | AVSS / DRVSS |
| Pin 5~18 | 数据线 | 见第 3 节 |

> 模块板载 AX1117-3.3V LDO 给 DRVDD 供电，因此外部只需给模块供 5V。
> 所有地线必须在模块上共地，外部只需把 GND 接到任意一个 GND 针。

## 3. AD9226 V1.4 模块 ↔ F407

### 3.1 P2 排针定义（2×10 双排，共 20 针）

P2 为 2×10 双排排针，以下按板上丝印编号（与厂商原理图一致）：

| P2 引脚 | 信号 | F407 引脚 | 说明 |
|---------|------|-----------|------|
| 1 / 2 | +5V | 5 V | 模块模拟 5V |
| 3 / 4 / 19 / 20 | GND | GND | 模块地 |
| 5 | D0 (LSB) | **PF0** | 最低位 |
| 6 | CLKIN | **PE9** | TIM1_CH1 PWM 采样时钟 |
| 7 | D2 | **PF2** | |
| 8 | D1 | **PF1** | |
| 9 | D4 | **PF4** | |
| 10 | D3 | **PF3** | |
| 11 | D6 | **PF6** | |
| 12 | D5 | **PF5** | |
| 13 | D8 | **PF8** | |
| 14 | D7 | **PF7** | |
| 15 | D10 | **PF10** | |
| 16 | D9 | **PF9** | |
| 17 | OTR | **PC12** | 超量程指示（可选） |
| 18 | D11 (MSB) | **PF11** | 最高位 |

> **关键**：D0/D1 被 CLK 隔开，不要按 P2 引脚顺序想当然；按丝印 **D0=LSB、D11=MSB** 一一对应到 `PF0~PF11`。
> 接线后 `GPIOF->IDR & 0x0FFF` 直接就是 12-bit ADC 码，无需移位。

### 3.2 时钟线

- F407 `PE9` → P2 Pin 6 `CLKIN`
- 默认 2.048 MHz 方波，3.3V 电平，50% 占空比
- 若使用等效采样，时钟频率会被 H7 动态改为 2.625~6 MHz（divider 28~64）

### 3.3 超量程指示（可选）

- 模块 `OTR` → F407 `PC12`（输入）
- 输入超量程时 OTR ≈ 3.3V；正常时为低
- 当前软件中 PC12 被配置为输入，但不参与主逻辑，仅用于硬件排查


## 4. F407 ↔ STM32H743（SPI1 全双工链路）

H743 负责频率/幅值参数计算并可通过命令槽建议采样率；该算法结果的板级时序仍须实测确认。

| F407 引脚 | 方向 | H743 引脚 | 说明 |
|-----------|------|-----------|------|
| PA5 | 输出 → | SPI1_SCK | 5.25 MHz 时钟 |
| PA6 | ← 输入 | SPI1_MISO | H743→F407 命令槽（16 B） |
| PA7 | 输出 → | SPI1_MOSI | F407→H743 4096 点样本 |
| PA4 | ← 输入 | 任意 GPIO 推挽输出 | H7_READY 握手，内部上拉 |
| GND | — | GND | 共地 |

> **NSS/CS 不接**：双方使用软件 NSS，无需片选。
> 旧方案用 SPI2 传命令，已废弃，当前只需 PA5/PA6/PA7 三根线 + PA4 握手。

### 4.1 握手说明

- F407 上电后把 PA4 配成输入 + 内部上拉；
- H743 准备好 SPI 接收后拉高 PA4；
- F407 检测到 PA4=1 才开始 SPI 全双工交换；
- 若 H743 未接入，PA4 由上拉拉高，F407 仍会尝试发送，便于独立调试。

## 5. F407 ↔ TJC 串口屏（USART2 HMI）

| F407 引脚 | 方向 | TJC 屏引脚 | 说明 |
|-----------|------|------------|------|
| PA2 | 输出 → | RX（HMI 第 1 脚或 4 脚，视屏线定义） | HMI 指令/波形数据 |
| PA3 | ← 输入 | TX（HMI 第 2 脚或 3 脚） | 触摸事件/状态 |
| GND | — | GND | 共地 |

> 波特率 **921600**，8N1，无流控。
> 屏端需配置为相同波特率，并确保页面名为 `page0`，波形控件名为 `s_wave`，频谱控件名为 `s_fft`。

### 5.1 常用 HMI 控件名

| 控件名 | 类型 | 用途 |
|--------|------|------|
| `s_wave` | Waveform / Curve | 时域波形 |
| `s_fft`  | Waveform / Curve | 频谱 |
| `t_vpp`  | Text | Vpp 数值 |
| `t_rms`  | Text | Vrms 数值 |
| `t_f1`   | Text | 基频 |
| `v01`/`v02`/`v03` | Text | 谐波幅度 |
| `f01`/`f02`/`f03` | Text | 谐波频率 |
| `T_num`  | Text | 周期数 1/3 |

## 6. F407 ↔ PC 调试串口（USART1）

| F407 引脚 | 方向 | USB-TTL 模块 | 说明 |
|-----------|------|--------------|------|
| PA9 | 输出 → | RX | 调试 printf / binary 镜像 |
| PA10 | ← 输入 | TX | 接收命令字符 d/r/q/p/e/f |
| GND | — | GND | 共地 |

> 波特率 **921600**（可在 CubeMX 或 `MX_USART1_UART_Init` 中修改）。
> 使用 `tio -b 921600 /dev/ttyUSB0` 等工具连接。


## 7. SWD 调试接口

| F407 引脚 | ST-Link 引脚 | 说明 |
|-----------|--------------|------|
| PA13 | SWDIO | 数据 |
| PA14 | SWCLK | 时钟 |
| NRST | NRST | 复位 |
| GND | GND | 共地 |
| 3.3V | 3.3V | 可选目标板供电 |

> 烧录/调试使用 OpenOCD 或 ST-Link Utility。SWD 占用了 PA13/PA14，不影响 PA15 作为按键（JTDI 输入引脚复用为 GPIO）。

## 8. 周期切换按键

| F407 引脚 | 接法 | 说明 |
|-----------|------|------|
| PA15 | 按键 → GND | 按下拉低，切换串口屏波形显示 1 周期 / 3 周期 |

- 按键释放时 PA15 保持高电平，按下时接地拉低；软件以 PA15/EXTI15 的下降沿记录按下事件。
- `screen_key.c` 的轮询路径以 30 ms 稳定电平消抖；IRQ 路径则在下降沿后等待
  至少 30 ms、并限制两次事件至少相隔 200 ms，但发布 IRQ 事件前不重新读取
  PA15。因此 IRQ 路径是延迟/最小间隔滤波，而不是稳定电平确认。
- PA15 原为 JTAG 的 JTDI 输入脚，现复用为 GPIO/EXTI15；PA13/PA14 的 SWDIO/SWCLK 保持用于 SWD 调试。

## 9. 信号源输入

### 9.1 AD9226 模块输入

- 使用模块上的 SMA 母座 J3（单端输入）；
- 中心针接信号，外壳接信号源地线；
- 模块内部通过 R2/R3 分压 + AD8138 单端→差分驱动后送入 AD9226。

### 9.2 量程说明

- 当前模块默认配置（MODE1=0、MODE2=1、SENSE=0）对应内部 1 Vp-p 差分量程；
- 前端分压后外部 SMA 最大约 4~5 Vp-p，实测标定见 `AD9226_标定参数_H7.md`；
- 若 OTR（PC12）变高，说明输入超量程。

### 9.3 信号源共地

- 函数发生器/信号源地线必须接到 F407 与 AD9226 的公共地；
- 建议使用同轴线或双绞线，降低共模噪声；
- 高频小信号时尽量缩短 SMA 到模块的线缆长度。

## 10. 接线检查清单

按顺序打勾，避免上电冒烟：

1. ☐ AD9226 模块 5V/GND 正确，未反接。
2. ☐ F407 与 AD9226、H743、TJC 屏、PC 共地。
3. ☐ PF0~PF11 逐根核对到 P2 的 D0~D11（注意 D0/D1 之间被 CLK 隔开）。
4. ☐ PE9 接到 P2 CLKIN。
5. ☐ PA5/PA6/PA7 接到 H743 SPI1，PA4 接 H7_READY。
6. ☐ PA2/PA3 接到 TJC 屏 TX/RX（交叉：F407 TX→屏 RX，F407 RX←屏 TX）。
7. ☐ PA9/PA10 接到 USB-TTL（交叉）。
8. ☐ PA13/PA14 接到 ST-Link SWD。
9. ☐ PA15 按键另一端接地。
10. ☐ 所有杜邦线/排线插紧，无松动。

## 11. 上电验证步骤

1. **只给 F407 上电**（暂不接 AD9226 5V 或 H743）：
   - 串口应输出启动日志：
     ```
     [1] UART OK (H7_READY=PA4, KEY=PA15, pullup)
     [2] AD9226_Init OK, Fs=2048780 Hz
     [2b] SpiCmd_Init OK
     [2c] ScreenApp_Init OK (USART2 PA2/PA3 -> TJC HMI)
     [3] AD9226_Start OK, entering loop
     ```

2. **接上 AD9226 5V/GND，不接信号**：
   - 用示波器探 PE9，确认 2.048 MHz 方波；
   - 串口发 `p`，mean 应约为 0x807（2055）附近；
   - 若 mean 为 0 或 0xFFF 锁死，检查时钟/数据线。

3. **SMA 中心短路到外壳（0 V 输入）**：
   - mean 应在 0x07F0 ~ 0x0810 之间；
   - pp（峰峰值）应很小（< 32 LSB）。

4. **接入 1 kHz / 1 Vpp 正弦**：
   - mean 应随信号在 0x0620 ~ 0x09DE 之间往返；
   - 屏幕应显示静止或缓慢滚动的正弦。

5. **接入 H743**：
   - H743 拉高 PA4 后，F407 开始 SPI 交换；
   - 串口应出现 `[CMD] SET_FS/SET_EQ_F0 ...` 日志。

## 12. 常见故障排查

| # | 现象 | 可能原因 | 排查 |
|---|------|----------|------|
| 1 | 上电冒烟 / 电流 > 500 mA | 5V/GND 接反、数据线搭到 +5V | 立即断电，重新核对 P2 引脚 |
| 2 | 串口无启动日志 | 波特率不对、USB-TTL TX/RX 接反、未烧录固件 | 检查 PA9 输出波形、重刷固件 |
| 3 | AD9226 mean 锁 0 或锁 0xFFF | PE9 时钟没通、数据线错位、SMA 开路 | 示波器测 PE9；对照 P2 表逐根测 PF0~PF11 |
| 4 | mean 正确但波形不静止 | H7 未返回 f0、或 `screen_build_frame` 未收到测量值 | 发 `p` 看 f0；检查 SPI1 MISO/PA4 |
| 5 | 屏幕无波形 | USART2 未接、波特率不一致、TJC 控件名错 | 检查 PA2/PA3；确认屏配置为 921600、page0 |
| 6 | FFT 多峰 / 谐波异常 | 采样时钟抖动、前端失真、重建周期不连续 | 确认已加 Hanning 窗；检查 f0 与 Fs 匹配 |
| 7 | 按键切换周期无效 | PA15 未接地、按键损坏、EXTI 未触发 | 万用表测 PA15 按下是否到低 |
| 8 | SPI1 通信失败 | PA5/PA6/PA7 虚焊、H7 未拉高 PA4、电平不匹配 | 示波器看 SCK/MOSI/MISO；确认共地 |
