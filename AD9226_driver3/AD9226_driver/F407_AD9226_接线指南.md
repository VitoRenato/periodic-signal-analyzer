# F407 AD9226 采集端接线指南

适用配置：STM32F407ZGT6、AD9226 V1.4 模块、STM32H743 与 TJC 串口屏。断电接线，核对模块 P2 丝印和板卡电平，所有设备共地。AD9226 模块 P2 由 5 V 供电，数字输出为 3.3 V。信号源接模块 SMA 输入，参考电压在实际输入端测量。

| 6 | CLKIN | **PE9** | TIM1_CH1 PWM 采样时钟 |
| 7 | D2 | **PF2** | |

## H743（SPI1）

| F407 | H743 | 信号 |
|---|---|---|
| PA5 | PA5 | SPI1 SCK，F407 输出 |
| PA6 | PA6 | SPI1 MISO，H743 回传 |
| PA7 | PA7 | SPI1 MOSI，F407 上传 |
| PA4 | PD0 | H743 `ACQ_READY` 输出，F407 PA4 输入上拉 |
| GND | GND | 共地 |

SPI1 使用软件 NSS。采样与模型数据格式见 [SPI1 通信协议](../../H743_Signal_Processor/H743_Signal_Processor/docs/COMMUNICATION_PROTOCOL.md)。

## 串口与按键

| 接口 | F407 | 对端 |
|---|---|---|
| TJC（USART2，921600 baud、8N1） | PA2 TX、PA3 RX、GND | 屏 RX、TX、GND |
| 调试（USART1，921600 baud、8N1） | PA9 TX、PA10 RX、GND | 3.3 V USB-TTL 的 RX、TX、GND |
| 测量按键 | PA15 | 按下接地 |
| SWD | PA13、PA14、GND，按需接 NRST | SWDIO、SWCLK、GND、NRST |

确认 PE9 有采样时钟后，再用 F407 的 `c` 命令检查完整原始帧。屏幕引脚和控件配置见 [TJC 屏幕工程](../../TJC_HMI/README.md)。
