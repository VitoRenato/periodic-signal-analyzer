# AD9226 采集端 → H743 电压标定参数

> 当前口径：H743 和屏幕统一输出 BNC 输入端电压。
> 采集硬件：STM32F407ZGT6 + AD9226 模块，板上交流通道增益 2 倍。
> 当前系数仍是临时值；赛题 ±5 mV 验收前必须做 BNC 端两点精校。

## 一、当前软件参数（2026-08-01）

| 参数 | 数值 | 单位 | 含义 |
|---|---:|---|---|
| `AD9226_ZERO_CODE` | 2055 | code | 无交流输入时的参考零码 |
| `AD9226_ADC_V_PER_CODE` | 0.005236 | V/code | ADC 前端电压临时换算系数 |
| `AD9226_FRONTEND_AC_GAIN` | 2.0 | 倍 | BNC 到 ADC 的交流增益 |
| `BNC_V_PER_CODE` | 0.002618 | V/code | 软件最终使用的 BNC 电压换算系数 |

H743 对外输出公式：

```c
bnc_V = ((adc_code - 2055) * 0.005236f) / 2.0f;
```

对应代码位于：

```text
H743_Signal_Processor/H743_Signal_Processor/Algorithm/Private/ad9226_calibration.h
```

## 二、为什么必须除以 2

题目设置的是装置 BNC 入口信号。板上前端对交流分量放大 2 倍，因此：

```text
BNC 输入 250 mVpp
    -> ADC 前端约 500 mVpp
    -> H743 计算后除以 2
    -> 屏幕显示约 250 mVpp
```

不能让 H743 输出 ADC 端电压、再由不同显示路径各自决定是否除以 2；所有算法指标必须统一使用 BNC 口径。

## 三、最近实板数据与当前限制

已观察到的干净工况：

```text
偏置约 1.65 V
ADC 原始范围约 [2071, 2177]
峰峰值 106 code
H743 旧口径报告约 533～534 mVpp
```

这说明 `0.005236 V/code` 与最近干净波形的 ADC 端幅度处在同一数量级，但它不是精密标定结果。按 2 倍增益换算后，106 code 对应 BNC 约：

```text
106 * 0.005236 / 2 = 0.2775 Vpp
```

若信号源 BNC 标称为 250 mVpp，仍有约 27.5 mV 偏差，明显不能证明达到 ±5 mV。

旧文档曾用削顶/异常范围 `[1222,2096]` 反推 `0.000627 V/code`。该方法把失真波形当成线性标定数据，与后续干净波形矛盾，现已停用。

## 四、BNC 端两点精校

1. 把偏置调到不会削顶的状态，仅用于标定。
2. 信号源设置一个较小正弦，例如 BNC 100 mVpp；用示波器在 BNC 座实测 `Vpp_bnc_1`。
3. 读取同一帧原始 `adc_max_1 - adc_min_1`。
4. 再使用接近题目满幅但仍不削顶的信号，记录 `Vpp_bnc_2` 和第二组码差。
5. 分别计算：

```text
BNC_V_PER_CODE_i = Vpp_bnc_i / (adc_max_i - adc_min_i)
ADC_V_PER_CODE_i = 2 * BNC_V_PER_CODE_i
```

6. 两个点的 `BNC_V_PER_CODE` 应基本一致；若差异超过赛题允许误差，应先检查前端线性、信号源 50 Ω 设置和示波器端接。
7. 用两点拟合后的 `ADC_V_PER_CODE` 更新 `ad9226_calibration.h`，重新运行主机测试和实板测试。

## 五、验证边界

- H743 主机测试通过只证明代码中的 ADC/BNC 两倍口径自洽。
- 1.65 V 偏置下完整波形只证明没有明显削顶，不代表 1.50 V 工况已恢复。
- 串口 `adc_min/max`、函数源标称值和屏幕显示值不能替代 BNC 示波器实测值。
- 只有 1.50 V 偏置下，赛题幅度/谐波组合实测均满足绝对误差 ≤5 mV，才能宣称完成幅值指标。
