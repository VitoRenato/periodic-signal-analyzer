# F407 AD9226 采集端技术手册

STM32F407ZGT6 采集 AD9226 并行数据，通过 SPI1 和 H743 交换数据，再通过 USART2 驱动 TJC 串口屏。完整接线见 [F407 接线指南](F407_AD9226_接线指南.md)。

| 接口 | 配置 |
|---|---|
| 并行数据 | AD9226 D0～D11 → PF0～PF11；OTR 接 PC12，用于硬件观测 |
| 采样时钟 | PE9 / TIM1_CH1，PWM1；默认 PSC=0、ARR=81、CCR1=41，定时器时钟 168 MHz |
| 采样 DMA | TIM1_UP → DMA2 Stream5 Channel 6，GPIOF 的 16 位半字到内存，4096 点 |
| 板间通信 | SPI1 主机，PA5/PA6/PA7；PA4 接 H743 的 READY |
| 串口屏 | USART2，PA2 TX、PA3 RX，921600 baud、8N1 |
| 调试 | USART1，PA9 TX、PA10 RX，921600 baud、8N1 |
| 测量按键 | PA15，内部上拉、按下接地；短按切换周期，长按重测 |

默认采样率约 2.04878 MSPS，采集一帧约 2 ms。这是 ADC 取样时间；整机出结果还需要板间交换、分析、模型确认和显示传输。H743 请求改变采样率时，F407 更新定时器分频并记录在采集头。GPIOF 半字按 `0x0FFF` 提取每点原始码。
