## 1. 总体结构

模块为一块独立的 AD9226 采集子板,通过 `P1`(电源)+ `P2`(信号)两个排针与外部 MCU(F407 / H7)对接。板上含 3 个有源器件 + 一路 3.3V LDO + LED 指示:

| 编号 | 型号 | 作用 |
|------|------|------|
| **U2**(V1.2) / **U1**(V1.4) | AD9226 | 12-bit 65 MSPS ADC(SSOP-28 / LQFP-48) |
| **U3** | AD8138 | 单端 → 差分 ADC 驱动器(8-pin SOIC) |
| **U5** | AX1117-3.3V | 5V → 3.3V LDO,只为 LED + DRVDD 供电 |
| **D1** | LED_1 | 电源指示 |
| **P1** | 2-pin POWER | +5V / GND 输入 |
| **P2** | 10×2 Header | 数字接口(CLK + D0..D11 + OTR + 电源) |
| **P3** | SMA | 单端模拟信号输入 |
| **P11** | 2-pin TEST | 输入侧测试点 |
| **J10~J13** | 铜柱 | 4 个固定/测试焊盘 |

## 2. 电源网络

```
P1 (+5V) ──► U5 (AX1117-3.3V) ──► +3.3V (DRVDD + LED)
                  │
                  ├── C1  100 µF / 10 V (输入)
                  ├── C3  1   µF        (输出)
                  │
                  ├── R1 1 kΩ ──► D1 LED ──► GND
```

| 电源轨 | 来源 | 给谁用 |
|--------|------|--------|
| **+5V** | P1 直入 | AD9226 AVDD;AD8138 V+;P2 pin 1/2 输出给外部 MCU |
| **+3.3V** | U5 LDO 输出 | AD9226 DRVDD(数字输出缓冲);D1 LED |
| **GND** | P1 | 全部模拟/数字地共地(单点 GND 符号星形布置) |

> ⚠️ 注意:板上**没有**模拟/数字地分割,所有地符号接同一 GND 铜皮。这对 65 MSPS ADC 来说噪声裕量偏紧。

## 3. AD9226 关键引脚连接(两版本一致)

以 V1.4 LQFP 为准(更清晰),V1.2 SSOP 引脚编号不同但功能一致。

### 3.1 模拟输入

| 引脚(LQFP-48) | 引脚(SSOP-28) | 名称 | 连接 |
|---|---|---|---|
| 46 | 23 | **VINA** | R9 (10 Ω) ← U3 +OUT |
| 47 | 24 | **VINB** | R11(10 Ω) ← U3 -OUT |
| 37 | 18 | VREF | C9 0.1 µF → GND(参考电压去耦) |
| 38 | 19 | REFCOM | C8 10 µF → GND(参考地去耦) |
| 36 | 17 | **SENSE** | **直接接 GND** |
| 35 / 43 | 22 | MODE1 / MODE2 | R33/R35 1 kΩ → GND |
| 48 | — | VR(VCOM) | C41 0.1 µF → GND |
| 45 | — | CML | C42 0.1 µF → GND |

**→ 关键结论:`SENSE = AVSS` ⇒ 内部 2.0 V 参考,VREF 引脚 = 2.0 V,差分输入范围 = ±2 V = 4 V p-p。**

每 LSB = `4 V / 4096 = 976.56 µV`,中点码值 = 2048。

### 3.2 数字输出 + 时钟

| 引脚 | 名称 | 网络 → P2 排针 |
|---|---|---|
| 7 | **CLK** | R15 (10 Ω) → P2.4(SSOP 中是 R4 → P2.1,**两版顺序不同**) |
| 9 | OEB | R31 1 kΩ 上拉到 +3.3V(P6 可强制拉低关闭输出) |
| 12–27 | BIT1–BIT12 | 各自串 **R7 / R10 / R12 排阻(10 Ω)** → P2 的 D0–D11 |
| 28 | OTR | R4 (10 Ω) → P2.15(SSOP)/ OTR(标定) |

排阻 10 Ω 是**源端串阻**,配合 AD9226 输出阻抗(典型 25 Ω)凑 35 Ω,与 50 Ω 传输线略有反射但用于 ~20 cm 杜邦线长度可接受。

### 3.3 电源去耦(V1.4 LQFP 标注)

| 引脚 | 退耦电容 |
|---|---|
| AVDD (3, 4, 31, 34) | C5 0.1 µF + C13 0.1 µF → +5V/GND |
| DRVDD (7, 15, 23, 29) | C4 0.1 µF → +3.3V/GND |
| AVSS (1, 2, 32, 33) | 直接 GND |
| DRVSS (14, 22, 30) | 直接 GND |
| CAPT1/2 (41, 42) | C6 0.1 µF + C8 10 µF → GND |
| CAPB1/2 (39, 40) | C7 0.1 µF + C9 0.1 µF → GND |

## 4. AD8138(U3)前端电路 ⭐ 重点

### 4.1 引脚功能(标准 SOIC-8,V1.4 标注与 datasheet 一致)

```
            ┌──────┐
   -IN  [1] │      │ [8] +IN
   Vocm [2] │ U3   │ [7] NC
   V+   [3] │AD8138│ [6] V-
   +OUT [4] │      │ [5] -OUT
            └──────┘
```

> V1.2 SSOP 版把引脚重排成"5/-OUT 6/V- 7/NC 8/+IN | 1/-IN 2/Vocm 3/V+ 4/+OUT",**功能完全相同,只是 pin number 标法不同**,**不要被引脚号搞混**。

### 4.2 单端 → 差分输入网络

```
                     ┌── R17 3 kΩ ── GND
                     │
   P3 (SMA) ────────┼── R8  75 Ω ── GND
                     │
                     └── R5 200 Ω ── R25 0 Ω ── R6 200 Ω ──┬── U3 +IN (8)
                                                              │
                                            P11.2 (TEST) ────┤
                                                              │
                                                          R3 62 Ω ── GND
```

- **P11.2** 是 R5 / R25 之间的"中间抽头",可以从这里注入测试信号(已经过 R5 衰减但跳过 R6)。
- **R8 (75 Ω) + R17 (3 kΩ) 到 GND**:给 SMA 中心抽头提供 DC 偏置回路(SMA 内部是耦合电容,所以需要 DC 回路)。
- **R5 + R6 = 400 Ω 与 R3 (62 Ω) 形成分压**,再叠加上 50 Ω 信号源内阻,从 SMA 到 U3 +IN 的**总衰减**为:

$$
\frac{V_{+IN}}{V_{SMA}} = \frac{62}{50 + 200 + 0 + 200 + 62} = \frac{62}{512} \approx 0.121 \quad (≈ -18.3 \text{ dB,衰减 8.3×})
$$

**这是板上第一级明显的衰减,等效 8.3× 输入分压,实际进入 AD8138 的电压只有 SMA 端 12%。**

### 4.3 AD8138 反馈与增益网络

```
                ┌──── R2 200 Ω ────┐
                │                  │
   U3 +IN ──────┤                  ├── U3 -OUT (5)
                │                  │
   U3 -IN (1) ──┤                  │
                │                  │
                R16 51 Ω           │
                │                  │
   GND ─────────┤                  │
                                  R13 200 Ω (???)
                                  │
                R14 200 Ω ────────┤
                                  │
                       U3 +OUT (4)┘
```

**L1.4 实际走线(V1.4 LQFP 看得最清楚):**

- **R2 (200 Ω)**:从 **+IN 节点**(R6 与 U3 +IN 之间)跨到 **-OUT (pin 5)**——**这是 cross-feedback,不是标准的 -OUT→-IN 反馈**。这是 AD8138 文档 Figure 41 / Figure 48 推荐用于"低增益单端→差分"的接法。
- **R3 (62 Ω)** :+IN → GND,提供 DC 偏置。
- **R13 (200 Ω)** 与 **R16 (51 Ω)** 串联,GND → R16 → R13 → U3 -IN(分压 = 51/(51+200) = 0.203 给 -IN 一个 DC 偏置)。
- **R14 (200 Ω)**:从 U3 +OUT → U1 VCOM(LQFP 才有的 VCOM 偏置,SSOP 版此电阻在 -IN 路径)。

### 4.4 AD8138 增益计算(cross-feedback 拓扑)

对该 cross-feedback 配置,差分输出电压近似为:

$$
G_{AD8138} \approx 1 + \frac{R_2}{R_3} = 1 + \frac{200}{62} \approx 4.23 \text{ 倍(单端电压)}
$$

对差分输出(±OUT 摆幅)来说,有效摆幅是单端的 2 倍,所以差分电压增益 ≈ **8.46×**。

### 4.5 整体前端传递函数(SMA → AD9226 VINA-VINB)

$$
\boxed{G_{\text{total}} = \underbrace{\frac{R_3}{R_s + R_5 + R_6 + R_3}}_{\approx 0.121} \times \underbrace{\left(1 + \frac{R_2}{R_3}\right)}_{\approx 4.23} \times \underbrace{2}_{\text{差分摆幅}} \approx 0.121 \times 8.46 \approx 1.02 \times}
$$

**结论:从 SMA 到 AD9226 差分输入,理论总增益 ≈ 1.0×(略大于 1,基本是 unity gain)。**

## 5. 数字接口 P2 排针定义

### 5.1 V1.4 LQFP 标注(推荐阅读此版本)

| Pin | 名称 | 备注 | Pin | 名称 | 备注 |
|---|---|---|---|---|---|
| 1 | **GND** | | 2 | **+5V** | 可给外部 MCU 供电 |
| 3 | **D0** (LSB/BIT1) | | 4 | **CLK** | 时钟输入 |
| 5 | D2 (BIT3) | | 6 | D1 (BIT2) | |
| 7 | D4 (BIT5) | | 8 | D3 (BIT4) | |
| 9 | D6 (BIT7) | | 10 | D5 (BIT6) | |
| 11 | D8 (BIT9) | | 12 | D7 (BIT8) | |
| 13 | D10 (BIT11) | | 14 | D9 (BIT10) | |
| 15 | **OTR** | | 16 | D11 (MSB/BIT12) | |
| 17 | GND | | 18 | +5V | |
| 19 | GND | | 20 | GND | |

**注意:V1.4 是按"低字节奇、高字节偶"分组,方便按字节并行读取;D0=LSB,D11=MSB。**

### 5.2 V1.2 SSOP 标注(早期版本,顺序混乱)

| Pin | 信号 | | Pin | 信号 |
|---|---|---|---|---|
| 1 | **CLK** (R4→U2.1) | | 2 | +5V |
| 3 | BIT6 | | 4 | BIT7 |
| 5 | BIT5 | | 6 | BIT4 |
| 7 | **OTR** (R15→U2.14) | | 8 | BIT3 |
| 9 | GND | | 10 | BIT2 |
| 11 | GND | | 12 | BIT1 |
| 13 | BIT12 (R7) | | 14 | GND |
| 15 | BIT11 (R10) | | 16 | GND |
| 17 | BIT10 | | 18 | BIT9 |
| 19 | BIT8 | | 20 | GND |

> ⚠️ **两版 P2 排针顺序不一样**。如果固件同时兼容两版板子,需要按位映射。V1.2 的 P2.1 是 CLK,V1.4 的 P2.4 才是 CLK——**千万别按同一份代码混用两块板**。

### 5.3 排针 10 Ω 源端串阻

每根 BIT 线都过 **R7 / R10 / R12 排阻(4×10 Ω SIP)**,作用:

1. 源端阻抗匹配(AD9226 输出阻抗 ~25 Ω + 10 Ω ≈ 35 Ω,接近 50 Ω 传输线)
2. 抑制高速瞬态电流(12-bit @ 65 MSPS 边沿 ~3 ns)
3. 减小反射振铃

## 7. ⭐ 跟用户 debug 现状的对照

### 7.1 用户的实测

> 50 mVpp 输入 → 看到 pp = 783 codes → 推算"7.6× 增益(Vref=1V 假设) 或 15.3× 增益(Vref=2V 假设)"

### 7.2 理论预期

按本电路分析(`Vref = 2V`,`G_total ≈ 1.0×`):

$$
V_{\text{diff}} = 50\,\text{mV}_{pp} \times 1.0 = 50\,\text{mV}_{pp}
$$
$$
\text{codes}_{pp} = \frac{50\,\text{mV}}{4\,\text{V}} \times 4096 \approx 51 \text{ codes}
$$

**理论只应看到 ~51 codes pp,实测 783,差 15.3×——与"Vref=2V 假设"下推算的 15.3× 完全吻合。**

### 7.3 这意味着什么(分层定位)

| 假设 | 验证方法 | 真因概率 |
|---|---|---|
| **A. 板上电阻与 schematic 不符**(R5/R6 被短接 / R3 变小) | 万用表测 P3 节点到 U3 +IN 之间的电阻 | ★★ 高 |
| **B. 实际板是 V1.2 SSOP,前端参数不同** | 看板上丝印 / 测 U1 封装 | ★★ 中 |
| **C. 用户端的 50 mVpp 标定不对**(信号源内阻、负载、衰减) | 用示波器直接测 SMA 端实际波形 | ★ 中 |
| **D. AD8138 接错/虚焊/反相** | 测 U3 周围 8 个电阻实装值 | ★★ 高 |
| **E. 50 Ω 不匹配导致反射叠加** | 改用高阻探头测 +IN / -IN 实测 | ★ 中 |
| **F. SENSE 实际接了 3V3**(Vref=1V,AD9226 内部 reference 被切到 1V 模式) | 测 U1 pin 36 对地电压 | ★★ 高 |

### 7.4 推荐的快速验证步骤(给到固件端)

1. **短路测试**:把 SMA 短接到 GND(0 V 输入),读 AD9226 输出的平均码值。
   - 期望 ~2048(±几十,AD8138 偏置引起)
   - 实测 ~2055 → ✓ 中点基本正确
2. **直流偏置测试**:用稳压源从 P11.2 注入 0 V、+0.5 V、-0.5 V 直流,记录码值。
   - 期望斜率 = `1 / 0.9766 mV ≈ 1024 codes/V`(差分 → 1 V 差分 = 1024 codes)
   - 实测斜率 → 即可算出**实际 Vref** 和**实际前端增益 G**
3. **Vref 实测**:用万用表 mV 档测 U1 pin 37 (VREF) 对 pin 38 (REFCOM) 电压。
   - 期望 2.000 V(±30 mV 容差)
   - 实测 ≈ 1.0 V → **真相大白:实际 Vref 是 1 V**,即 SENSE 被错误接到 DRVDD(3.3 V),把内部 ref 切到 1 V 模式
4. **前端增益核对**:测 U3 pin 8 (+IN) 对地交流电压(高阻探头),同时看 SMA 端电压,两者比值 ≈ `R3/(R5+R6+R3) = 0.121`。
   - 如果测到 ~0.5 → R5/R6 被短接
5. **重算 `SCALE_UV_PER_CODE`**:用实测 Vref 重算,**预期 = 4096 / (2 × Vref实测) × 1e6 µV/V**。
   - 例:Vref=1V → `SCALE = 4096/2/1e6 = 488 µV/code`
   - 例:Vref=2V → `SCALE = 4096/4/1e6 = 244 µV/code`(注意:这是单端换算;差分 pp 应是 `2 × 488 = 976 µV/code`)

### 7.5 给出 7.6× / 15.3× 自洽解释的最可能模型

| 项 | 取值 | 来源 |
|---|---|---|
| 实际 Vref | **1.0 V** | SENSE 接 3V3(板上飞线或丝印错) |
| 1 LSB | 488.3 µV | 2 V / 4096 |
| 实际前端增益 | **7.65×** | = `783 codes × 488.3 µV / 50 mV` |
| 反推 R5/R6 + R3 配置 | 增益 = 0.121 × 4.23 = 0.51 → 实测 7.65 → 差 15× | **板上 R5、R6 中至少一个被换成 0 Ω,或 R3 被换大** |
| 或 AD8138 接成不同拓扑 | R2 实际接 -OUT→-IN(标准)而非 -OUT→+IN(cross) | 改接后增益 = (1+200/62)×2 = 8.46;若 R5、R6 短接 → 8.46× → 接近 7.65× |

**最可能真因:① SENSE 飞线到 3V3 + ② R5 或 R6 至少一个实际是 0 Ω(或 0805 漏装)。**

## 8. 设计疑点 / 坑(给硬件/固件联调的人)

1. **没有 AC 耦合电容**:前端 DC 耦合,如果信号源中心不是 0 V,会直接进 AD8138 共模,可能顶到 rail。
   - 解决:信号源串 10 µF + 100 Ω 隔直;或确认源是 AC-coupled
2. **50 Ω 不匹配**:R8 (75 Ω) 不等于 50 Ω,实测驻波比约 1.5,高速信号会有反射。
   - 解决:把 R8 换成 49.9 Ω
3. **R5 + R6 = 400 Ω 串联在信号路径上**是过度衰减,要么改小(20~50 Ω)要么把 R3 减小到 20 Ω 以下以提增益。
4. **OCB/OTR 在 P2 紧挨着 BIT12**,布线时务必隔开一根 GND(SSOP 版没有,这是个 BUG)。
5. **V1.2 vs V1.4 P2 排针顺序不同**(CLK 在 P2.1 vs P2.4),**固件不能通用**。
6. **板上没有 SPI/并口选择跳线**,固定是 12-bit 并口。如果 MCU 端 SPI 采样,需要在 MCU 侧加并转串(如 74HC595 或 GPIO 模拟)。
7. **AD8138 的 Vocm 没有驱动**(C12 0.1 µF → GND 浮空),靠内部偏置,共模点可能随 Vref 漂移。
8. **U5 AX1117-3.3V 的 C1 用 100 µF/10V 太靠近输入阻抗限值**,实际纹波抑制比 datasheet 略低;如果想干净点换成 220 µF 或加 π 滤波。
9. **DRVDD 上没有 ferrite bead 或电感**,数字噪声会直接耦合到模拟地。至少 10 Ω + 10 µF 形成 π 滤波会更好。
10. **J10~J13 四个铜柱只标了 GND**,没有用作测试点。建议至少留一个接 SMA 外壳(GND),一个接 +5V,便于示波器就近探测。

## 9. 与本项目 F407 / H7 固件的接口建议

1. **CLK 必须 ≤ 65 MHz**,且占空比 45~55%。
2. **数据在 CLK 上升沿后 ~5 ns 有效**(AD9226 datasheet tOD),MCU 侧在 CLK 下降沿采样最稳。
3. **OTR 在溢出时立即拉高,需要 ISR 立即降增益**(MGC 脚接电位器调中点)。
4. **每次上电做一次 DC 自校准**:短路 SMA 读中点码,作为 `ZERO_CODE` 写入 viewer。
5. **用 `SCALE_UV_PER_CODE = 2 × Vref / 4096 × 1e6`**(单位 µV)——务必先实测 Vref,别用 5236 这种 magic number。
