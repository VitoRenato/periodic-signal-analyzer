## 1. 总体结构

模块为一块独立的 AD9226 采集子板,通过 `P1`(电源)+ `P2`(信号)两个排针与外部 MCU(F407 / H7)对接。板上含 3 个有源器件 + 一路 3.3V LDO + LED 指示:

| 编号 | 型号 | 作用 |
|------|------|------|
| **U2**(V1.2) / **U1**(V1.4) | AD9226 | 12-bit 65 MSPS ADC(SSOP-28 / LQFP-48) |
| **U3** | AD8138 | 单端 → 差分 ADC 驱动器(8-pin SOIC) |
| **U5** | AX1117-3.3V | 5V → 3.3V LDO,只为 LED + DRVDD 供电 |
| **D1** | LED_1 | 电源指示 |
| **P1** | 2-pin POWER | +5V / GND 输入 |
| **P2** | 10×2 Header | 数字接口(CLK + D0..D11 + OTR + 电源) |
| **P3** | SMA | 单端模拟信号输入 |
| **P11** | 2-pin TEST | 输入侧测试点 |
| **J10~J13** | 铜柱 | 4 个固定/测试焊盘 |

## 2. 电源网络

```
P1 (+5V) ──► U5 (AX1117-3.3V) ──► +3.3V (DRVDD + LED)
                  │
                  ├── C1  100 µF / 10 V (输入)
                  ├── C3  1   µF        (输出)
                  │
                  ├── R1 1 kΩ ──► D1 LED ──► GND
```

| 电源轨 | 来源 | 给谁用 |
|--------|------|--------|
| **+5V** | P1 直入 | AD9226 AVDD;AD8138 V+;P2 pin 1/2 输出给外部 MCU |
| **+3.3V** | U5 LDO 输出 | AD9226 DRVDD(数字输出缓冲);D1 LED |
| **GND** | P1 | 全部模拟/数字地共地(单点 GND 符号星形布置) |

> ⚠️ 注意:板上**没有**模拟/数字地分割,所有地符号接同一 GND 铜皮。这对 65 MSPS ADC 来说噪声裕量偏紧。

## 3. AD9226 关键引脚连接(两版本一致)

以 V1.4 LQFP 为准(更清晰),V1.2 SSOP 引脚编号不同但功能一致。

### 3.1 模拟输入

| 引脚(LQFP-48) | 引脚(SSOP-28) | 名称 | 连接 |
|---|---|---|---|
| 46 | 23 | **VINA** | R9 (10 Ω) ← U3 +OUT |
| 47 | 24 | **VINB** | R11(10 Ω) ← U3 -OUT |
| 37 | 18 | VREF | C9 0.1 µF → GND(参考电压去耦) |
| 38 | 19 | REFCOM | C8 10 µF → GND(参考地去耦) |
| 36 | 17 | **SENSE** | **直接接 GND** |
| 35 / 43 | 22 | MODE1 / MODE2 | R33/R35 1 kΩ → GND |
| 48 | — | VR(VCOM) | C41 0.1 µF → GND |
| 45 | — | CML | C42 0.1 µF → GND |

**→ 关键结论:`SENSE = AVSS` ⇒ 内部 2.0 V 参考,VREF 引脚 = 2.0 V,差分输入范围 = ±2 V = 4 V p-p。**

每 LSB = `4 V / 4096 = 976.56 µV`,中点码值 = 2048。

### 3.2 数字输出 + 时钟

| 引脚 | 名称 | 网络 → P2 排针 |
|---|---|---|
| 7 | **CLK** | R15 (10 Ω) → P2.4(SSOP 中是 R4 → P2.1,**两版顺序不同**) |
| 9 | OEB | R31 1 kΩ 上拉到 +3.3V(P6 可强制拉低关闭输出) |
| 12–27 | BIT1–BIT12 | 各自串 **R7 / R10 / R12 排阻(10 Ω)** → P2 的 D0–D11 |
| 28 | OTR | R4 (10 Ω) → P2.15(SSOP)/ OTR(标定) |

排阻 10 Ω 是**源端串阻**,配合 AD9226 输出阻抗(典型 25 Ω)凑 35 Ω,与 50 Ω 传输线略有反射但用于 ~20 cm 杜邦线长度可接受。

### 3.3 电源去耦(V1.4 LQFP 标注)

| 引脚 | 退耦电容 |
|---|---|
| AVDD (3, 4, 31, 34) | C5 0.1 µF + C13 0.1 µF → +5V/GND |
| DRVDD (7, 15, 23, 29) | C4 0.1 µF → +3.3V/GND |
| AVSS (1, 2, 32, 33) | 直接 GND |
| DRVSS (14, 22, 30) | 直接 GND |
| CAPT1/2 (41, 42) | C6 0.1 µF + C8 10 µF → GND |
| CAPB1/2 (39, 40) | C7 0.1 µF + C9 0.1 µF → GND |

## 4. AD8138(U3)前端电路 ⭐ 重点

### 4.1 引脚功能(标准 SOIC-8,V1.4 标注与 datasheet 一致)

```
            ┌──────┐
   -IN  [1] │      │ [8] +IN
   Vocm [2] │ U3   │ [7] NC
   V+   [3] │AD8138│ [6] V-
   +OUT [4] │      │ [5] -OUT
            └──────┘
```

> V1.2 SSOP 版把引脚重排成"5/-OUT 6/V- 7/NC 8/+IN | 1/-IN 2/Vocm 3/V+ 4/+OUT",**功能完全相同,只是 pin number 标法不同**,**不要被引脚号搞混**。

### 4.2 单端 → 差分输入网络

```
                     ┌── R17 3 kΩ ── GND
                     │
   P3 (SMA) ────────┼── R8  75 Ω ── GND
                     │
                     └── R5 200 Ω ── R25 0 Ω ── R6 200 Ω ──┬── U3 +IN (8)
                                                              │
                                            P11.2 (TEST) ────┤
                                                              │
                                                          R3 62 Ω ── GND
```

- **P11.2** 是 R5 / R25 之间的"中间抽头",可以从这里注入测试信号(已经过 R5 衰减但跳过 R6)。
- **R8 (75 Ω) + R17 (3 kΩ) 到 GND**:给 SMA 中心抽头提供 DC 偏置回路(SMA 内部是耦合电容,所以需要 DC 回路)。
- **R5 + R6 = 400 Ω 与 R3 (62 Ω) 形成分压**,再叠加上 50 Ω 信号源内阻,从 SMA 到 U3 +IN 的**总衰减**为:

$$
\frac{V_{+IN}}{V_{SMA}} = \frac{62}{50 + 200 + 0 + 200 + 62} = \frac{62}{512} \approx 0.121 \quad (≈ -18.3 \text{ dB,衰减 8.3×})
$$

**这是板上第一级明显的衰减,等效 8.3× 输入分压,实际进入 AD8138 的电压只有 SMA 端 12%。**

### 4.3 AD8138 反馈与增益网络

```
                ┌──── R2 200 Ω ────┐
                │                  │
   U3 +IN ──────┤                  ├── U3 -OUT (5)
                │                  │
   U3 -IN (1) ──┤                  │
                │                  │
                R16 51 Ω           │
                │                  │
   GND ─────────┤                  │
                                  R13 200 Ω (???)
                                  │
                R14 200 Ω ────────┤
                                  │
                       U3 +OUT (4)┘
```

**L1.4 实际走线(V1.4 LQFP 看得最清楚):**

- **R2 (200 Ω)**:从 **+IN 节点**(R6 与 U3 +IN 之间)跨到 **-OUT (pin 5)**——**这是 cross-feedback,不是标准的 -OUT→-IN 反馈**。这是 AD8138 文档 Figure 41 / Figure 48 推荐用于"低增益单端→差分"的接法。
- **R3 (62 Ω)** :+IN → GND,提供 DC 偏置。
- **R13 (200 Ω)** 与 **R16 (51 Ω)** 串联,GND → R16 → R13 → U3 -IN(分压 = 51/(51+200) = 0.203 给 -IN 一个 DC 偏置)。
- **R14 (200 Ω)**:从 U3 +OUT → U1 VCOM(LQFP 才有的 VCOM 偏置,SSOP 版此电阻在 -IN 路径)。

### 4.4 AD8138 增益计算(cross-feedback 拓扑)

对该 cross-feedback 配置,差分输出电压近似为:

$$
G_{AD8138} \approx 1 + \frac{R_2}{R_3} = 1 + \frac{200}{62} \approx 4.23 \text{ 倍(单端电压)}
$$

对差分输出(±OUT 摆幅)来说,有效摆幅是单端的 2 倍,所以差分电压增益 ≈ **8.46×**。

### 4.5 整体前端传递函数(SMA → AD9226 VINA-VINB)

$$
\boxed{G_{\text{total}} = \underbrace{\frac{R_3}{R_s + R_5 + R_6 + R_3}}_{\approx 0.121} \times \underbrace{\left(1 + \frac{R_2}{R_3}\right)}_{\approx 4.23} \times \underbrace{2}_{\text{差分摆幅}} \approx 0.121 \times 8.46 \approx 1.02 \times}
$$

**结论:从 SMA 到 AD9226 差分输入,理论总增益 ≈ 1.0×(略大于 1,基本是 unity gain)。**

## 5. 数字接口 P2 排针定义

### 5.1 V1.4 LQFP 标注(推荐阅读此版本)

| Pin | 名称 | 备注 | Pin | 名称 | 备注 |
|---|---|---|---|---|---|
| 1 | **GND** | | 2 | **+5V** | 可给外部 MCU 供电 |
| 3 | **D0** (LSB/BIT1) | | 4 | **CLK** | 时钟输入 |
| 5 | D2 (BIT3) | | 6 | D1 (BIT2) | |
| 7 | D4 (BIT5) | | 8 | D3 (BIT4) | |
| 9 | D6 (BIT7) | | 10 | D5 (BIT6) | |
| 11 | D8 (BIT9) | | 12 | D7 (BIT8) | |
| 13 | D10 (BIT11) | | 14 | D9 (BIT10) | |
| 15 | **OTR** | | 16 | D11 (MSB/BIT12) | |
| 17 | GND | | 18 | +5V | |
| 19 | GND | | 20 | GND | |

**注意:V1.4 是按"低字节奇、高字节偶"分组,方便按字节并行读取;D0=LSB,D11=MSB。**

### 5.2 V1.2 SSOP 标注(早期版本,顺序混乱)

| Pin | 信号 | | Pin | 信号 |
|---|---|---|---|---|
| 1 | **CLK** (R4→U2.1) | | 2 | +5V |
| 3 | BIT6 | | 4 | BIT7 |
| 5 | BIT5 | | 6 | BIT4 |
| 7 | **OTR** (R15→U2.14) | | 8 | BIT3 |
| 9 | GND | | 10 | BIT2 |
| 11 | GND | | 12 | BIT1 |
| 13 | BIT12 (R7) | | 14 | GND |
| 15 | BIT11 (R10) | | 16 | GND |
| 17 | BIT10 | | 18 | BIT9 |
| 19 | BIT8 | | 20 | GND |

> ⚠️ **两版 P2 排针顺序不一样**。如果固件同时兼容两版板子,需要按位映射。V1.2 的 P2.1 是 CLK,V1.4 的 P2.4 才是 CLK——**千万别按同一份代码混用两块板**。

### 5.3 排针 10 Ω 源端串阻

每根 BIT 线都过 **R7 / R10 / R12 排阻(4×10 Ω SIP)**,作用:

1. 源端阻抗匹配(AD9226 输出阻抗 ~25 Ω + 10 Ω ≈ 35 Ω,接近 50 Ω 传输线)
2. 抑制高速瞬态电流(12-bit @ 65 MSPS 边沿 ~3 ns)
3. 减小反射振铃
