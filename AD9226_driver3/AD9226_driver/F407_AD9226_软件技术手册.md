## 2. 系统架构与数据流

### 2.1 总体框图

```text
信号源 ──▶ AD9226 模块 ──┬──▶ F407 GPIOC[0..11]  (12 bit 并行数据)
                         │
                         └──▶ F407 PE9  (TIM1_CH1 PWM 采样时钟, 5 kHz~20 MHz)

F407 内部：
  TIM1_UP ──▶ DMA2_Stream5 ──▶ s_adc_buf[4096] (uint16_t)
       │
       ├──▶ SPI1 全双工 ──▶ H743 (样本 + 命令槽)
       ├──▶ USART1 ──▶ PC 调试 / binary 镜像
       └──▶ 本地重建 ──▶ 串口屏 (USART2 HMI)

H743 返回：
  命令槽 SET_FS + 五页测量模型 (f0/Upp/Urms/阶次/峰值/相位)
```

### 2.2 主要模块

| 模块 | 文件 | 职责 |
|------|------|------|
| AD9226 驱动 | `Core/Src/ad9226.c` | 启动 TIM1 PWM、配置 DMA、设置采样率 / 等效采样基频 |
| 等效采样/重建 | `Core/Src/equivalent_sampling.c` | 相位折叠重建、普通采样重建、256 点 FFT |
| 命令解析 | `Core/Src/spicmd.c` | 解析 H7 通过 SPI1 MISO 回传的命令槽 |
| 五页组装 | `USER/protocol/h743_measurement_rx.c` | CRC/页序/模型代号校验，完整后原子发布 |
| 模型显示 | `USER/app/screen_signal_model.c` | 按整数阶次、峰值幅度和余弦相位生成波形/谱线 |
| 主循环 | `Core/Src/main.c` | ADC 完成处理、SPI 交换、显示帧构建、串口命令 |
| 串口屏应用 | `USER/app/screen_app.c` | 刷新调度、按键/触摸处理、与 HMI 视图层对接 |
| 视图渲染 | `USER/app/screen_view.c` | 把 `ScreenDataFrame` 渲染为 HMI 波形/频谱/数值 |
| HMI 协议 | `USER/drivers/hmi_tjc.c` | TJC 串口屏指令（文本、曲线、addt 批量数据） |
| 按键驱动 | `USER/bsp/screen_key.c` | PA15 按键去抖，切换 1/3 周期显示 |

### 2.3 一帧数据流

1. `AD9226_Start()` 启动 DMA，`TIM1_UP` 每周期把 `GPIOC->IDR` 搬运到 `s_adc_buf[4096]`。
2. DMA 完成 → `HAL_DMA_XferCpltCallback` 置 `s_adc_done`。
3. `main()` 中 `AD9226_IsDone()` 为真后：
   - 通过 `AcqSpi_SendSamples()` 把 4096 点经 SPI1 MOSI 发给 H7；
   - 通过 `AcqSpi_RecvCmd()` 从 SPI1 MISO 接收 16 B 命令槽；
   - `SpiCmd_ProcessRx()` 解析命令槽，可能修改采样率或进入等效采样模式；
   - 同一模型代号的0~4页全部合法后，一次性发布完整模型；
   - 优先按H743模型生成1/3周期波形和真实频率谱线；
   - 模型尚未到齐或无效时，旧等效/普通重建仅作为RAW调试回退；
   - 构建`ScreenDataFrame`并通过`ScreenApp_SetFrame()`交给显示任务。
4. `ScreenApp_Task()` 按 `SCREEN_REFRESH_INTERVAL_MS`（默认 300 ms）把帧渲染到 TJC 串口屏。

## 3. 硬件抽象层

### 3.1 AD9226 驱动 (`ad9226.c`)

- **TIM1 PWM**：`PE9` 输出采样时钟，默认 `168 MHz / 82 ≈ 2.04878 MHz`。
- **DMA**：`DMA2_Stream5 Channel6`，由 `TIM1_UP` 触发，方向 `PERIPH_TO_MEMORY`，数据宽度半字（16 bit）。
- **采样率范围**：`5 kHz ~ 20 MHz`，通过改写 `TIM1_ARR` 实现：`ARR = 168 MHz / Fs - 1`。
- **采样完成回调**：`HAL_DMA_XferCpltCallback()` 仅置标志、关闭 DMA 请求，不做数据运算。

### 3.2 等效采样状态

| 接口 | 说明 |
|------|------|
| `AD9226_SetEqFundamental(f0_hz)` | 根据 f0 自动选 divider（28~64），改 TIM1 频率为 `168 MHz / divider` |
| `AD9226_ClearEqMode()` | 退出等效采样，恢复普通采样（不改变当前 Fs） |
| `AD9226_GetEqDivider()` | 返回**帧启动时捕获**的实际 divider，确保重建与采样时钟一致 |

### 3.3 SPI1 全双工 H7 链路

- **F407**：Master，2-LINES，8 bit，CPOL/CPHA = 0/0，预分频 16 → 5.25 MHz。
- **NSS**：软件模式，无片选线。
- **握手**：`PA4` 作为 `H7_READY` 输入，内部上拉。F407 等 H7 拉高后再发 SPI；H7 未接时上拉保证“无脑发”。
- **一帧长度**：`8208 B = 16 B 命令槽 + 8192 B 样本`。

### 3.4 USART1（调试 / binary 镜像）

- 波特率 `921600`，8N1。
- `printf` 用于调试；`dump_frame_binary()` 用于把 4096 点 raw 样本以固定帧头发给 PC viewer。
- 调试命令见第 9 节。

### 3.5 USART2（TJC HMI 串口屏）

- `PA2_TX` / `PA3_RX`，波特率 `921600`，8N1。
- 发送 HMI 指令和 `addt` 批量曲线数据；接收触摸事件。

### 3.6 按键

- `PA15` 为低有效物理按键：按键接至 GND，按下时拉低；下降沿通过 EXTI15 捕获。
- 轮询路径会在原始电平保持 30 ms 后更新稳定状态；IRQ 挂起路径仅在事件后等待
  至少 30 ms，并把两次按键事件的最小间隔限制为 200 ms，**不会在发布 IRQ 事件前
  再读取 PA15 确认低电平**。因此它是延迟/最小间隔滤波，不是 IRQ 级别的稳定电平确认。
- 功能：切换串口屏波形显示 1 周期 / 3 周期。
- PA15 从 JTAG 的 JTDI 输入脚复用为 GPIO/EXTI15；SWD 的 PA13/PA14 保持可用。


## 4. 采样与重建算法

### 4.1 常量与数据结构

```c
#define ES_EQ_SAMPLE_COUNT   4096U   // 每帧原始 ADC 点数
#define ES_PERIOD_POINTS     256U    // 一个基频周期的重建点数
#define ES_MAX_DISPLAY_POINTS 768U   // 最大显示点数（3×256）
#define ES_TIMER_CLOCK_HZ    168000000UL
#define ES_TIMER_DIVIDER_MIN 28U
#define ES_TIMER_DIVIDER_MAX 64U
```

重建出的一个周期始终为 **256 点 signed int16**（2048 = 0 V 中点），显示时再映射到 0~4095。

### 4.2 等效采样重建 `EsReconstructPeriod`

适用条件：F407 被 H7 设置为等效采样模式（`SET_EQ_F0`），实际采样率 `Fs = 168 MHz / divider` 远低于信号基频，单帧 raw 数据只含少量样点/周期。

算法步骤：

1. **相位增量**：
   ```c
   increment = (f0 * divider << 32) / 168 MHz
   ```
   用 32 位相位累加器表示一个完整周期，`phase >> 24` 得到 256 个相位 bin 之一。
2. **折叠**：把 4096 个采样点按相位投入 256 个 bin，同一 bin 多次采样取平均，降低随机噪声。
3. **插值补齐**：空 bin 用左右最近有效 bin 按距离加权线性插值。
4. **相位对齐**：用基频正弦/余弦分量估计周期相位，把波形对齐到同一零起点，保证屏幕波形静止。

### 4.3 普通采样重建 `NormalReconstructPeriod`

适用条件：每周期采样点数足够（通常 `Fs/f0 ≥ 2`，优先 `≥ 10`），直接从 raw ADC 截取一个完整周期。

当前实现要点：

- 计算精确的小数周期长度 `samples_per_period = Fs / f0`，不再强制取整为 `N` 个样本，避免首尾不连续导致的 FFT 频谱泄漏。
- 从 raw buffer 中找到第一个**上升过零点** `samples[i] ≤ 0 && samples[i+1] > 0`，锁定相位。
- 对 256 个输出点按相位 `0~1` 做线性插值：
  ```c
  fidx = start + phase * samples_per_period;
  period[i] = samples[idx0] + frac * (samples[idx1] - samples[idx0]);
  ```
  其中索引使用模 `sample_count` 回绕，相位=1 时正好落在下一个过零点，保证周期闭合。

### 4.4 普通 / 等效采样选择策略

`screen_build_frame()` 中的逻辑：

- 若 `period != NULL`（已在等效模式 ISR 中重建）：直接使用该周期，但满足 `Fs ≥ 10·f0` 时改走普通重建，避免等效采样的暂态/混叠使波形看起来像三角波。
- 否则（普通模式）：
  - `Fs/f0 < 10`：优先 `EsReconstructPeriod`；失败则 `NormalReconstructPeriod`。
  - `Fs/f0 ≥ 10`：优先 `NormalReconstructPeriod`；失败则 `EsReconstructPeriod`。
  - 两者都失败：使用**合成正弦回退**。

### 4.5 小信号处理

#### 4.5.1 显示增益 `screen_normalize_small_period`

重建后的 256 点可能只有十几个 ADC 码的跨度（例如 50 mVpp 信号），直接显示会看到量化台阶。该函数在显示前做动态缩放：

- 找出周期内的 `min_v`、`max_v`；
- 若峰峰值小于 `SCREEN_DISPLAY_MIN_RANGE_CODES`（当前 64 码），把波形幅度拉伸到 64 码；
- 只影响屏幕视觉高度，不影响 `frame->vpp_uv` 等 H7 测量标签。

#### 4.5.2 正弦拟合 `screen_sine_fit_period`

对 256 点做最小二乘正弦拟合 `y = offset + a·sin(θ) + b·cos(θ)`，输出平滑理想正弦。

触发条件 `screen_should_sine_fit()`：

- Vpp < 80 mV：强制拟合；
- 80 mV ≤ Vpp < 150 mV：且谐波总量 < 基波 1/4 时才拟合；
- Vpp ≥ 150 mV：不拟合，保留原始波形以正确显示方波/三角波。

#### 4.5.3 合成正弦回退 `screen_synth_sine_period`

当两种重建都失败时，根据 raw ADC 的 `min/max` 合成一个理想正弦周期，保证屏幕始终有可读波形（代价是丢失谐波形状）。


## 5. 频谱与谐波提取

### 5.1 256 点 FFT `ComputePeriodSpectrum`

对 256 点单周期做基 2 FFT，输出 256 点幅度谱。

当前实现：

1. 去掉直流分量（周期均值置零）；
2. 加 **Hanning 窗**：`w[i] = 0.5 - 0.5·cos(2π·i / 255)`，抑制非相干采样导致的频谱泄漏；
3. 复数基 2 FFT；
4. 计算 `mag = sqrt(real² + imag²)`，裁剪到 `uint16_t`。

> 加窗后主瓣会展宽，但旁瓣从矩形窗的约 -13 dB 降到约 -31 dB，可显著减少“假谐波”尖峰。

### 5.2 模型谱线与RAW回退

主路径由`ScreenSignalModel_FillSpectrum()`直接使用H743模型，频率为
`order * f0`，幅度为BNC输入端正弦峰值。

只有模型尚未完整发布时，旧`screen_extract_harmonics()`才从RAW重建FFT做
调试回退；其输入是`spectrum[256]`、采样率`Fs`、基频`f0`和`Vpp`。

步骤：

1. **基频定位**：在 `expected_bin = f0 * 256 / Fs` 附近 `±2 bin` 找最大幅度 `fundamental_mag`。
2. **基频回退幅度**：用`Vpp/2`作为峰值，不换算为RMS。
3. **2、3 次谐波**：
   - 谐波 bin 期望值 `h·expected_bin`；
   - 在 `±2 bin` 窗口内找峰值 `peak_mag`；
   - 仅当 `peak_mag ≥ fundamental_mag / 20`（≥ 5%）时才显示该谐波；
   - 频率直接写 `h·f0`，幅度按 `peak_mag / fundamental_mag` 比例换算。

### 5.3 FFT 显示

- `frame->fft_count = 128`，只传前 128 个 bin（0~Nyquist）。
- `screen_view.c` 取前 `SCREEN_FFT_VISIBLE_POINTS = 240` 点，按 `frame->fft_count` 均匀重采样后映射到 210 像素高度。
- FFT 曲线按最大值归一化，所以主要显示各频率分量的相对幅度。

## 6. 显示层

### 6.1 `ScreenDataFrame` 协议

定义见 `USER/protocol/screen_protocol.h`：

```c
typedef struct {
  uint32_t magic;            // 0x32434445 "EDC2"
  uint16_t version;          // 1
  uint16_t byte_len;         // sizeof(ScreenDataFrame) = 1084
  uint32_t sequence;
  uint32_t frequency_mhz;    // Hz * 1000
  uint32_t vpp_uv;
  uint32_t vrms_uv;
  uint32_t harmonic_freq_mhz[3];
  uint32_t harmonic_peak_uv[3];
  uint16_t wave_count;       // 768
  uint16_t fft_count;        // 128
  uint8_t mode;              // 0=WAVE, 1=FFT
  uint8_t wave_periods;      // 1 或 3
  uint8_t reserved[2];
  uint16_t wave[768];
  uint16_t fft[256];
  uint32_t checksum;         // sum32(前 1080 字节)
} ScreenDataFrame;
```

校验：`checksum = sum32((uint8_t *)&frame, byte_len - 4)`。

### 6.2 时域波形渲染 `ScreenView_RenderWave`

- 使用 `wave_count` 点（实际固定 768）。
- 按**动态范围**缩放：先找出 768 点中的 `min/max`，把 `min` 映射到底部、`max` 映射到顶部，上下各留 10 像素边距。
- 小信号因此能充满屏幕，但台阶感取决于原始量化；配合第 4.5 节的显示增益和正弦拟合可改善。
- 周期切换时调用 `HMI_ClearWave` 清屏，避免残留。

### 6.3 频域波形渲染 `ScreenView_RenderFft`

- 显示点数取 `min(fft_count, 240)`。
- 对 240 个可见点按 `fft_count` 做线性插值后映射到高度。
- 归一化到 `max(fft)`，便于观察相对谐波幅度。

### 6.4 周期切换

- `PA15` 按键或 TJC 屏触摸切换 `SCREEN_WAVE_PERIOD_1` / `SCREEN_WAVE_PERIOD_3`。
- 1 周期：256 点插值到 768 点显示；
- 3 周期：256 点周期重复 3 次填满 768 点。


## 7. 通信协议

### 7.1 SPI1 命令槽（H7 → F407）

命令槽长 **16 字节**，前10字节为SET_FS头，后6字节为五页测量模型。

| 偏移 | 字段 | 类型 | 说明 |
|------|------|------|------|
| 0-1  | magic    | u16 LE | `0xA55A`；填 0 表示 NOP |
| 2    | type     | u8     | `0x00`=NOP，`0x01`=SET_FS，`0x02`=SET_EQ_F0 |
| 3    | flags    | u8     | bit0有效、bit1削顶恢复、bit2~4页号、bit5~7模型代号 |
| 4-7  | payload  | u32 LE | SET_FS=目标采样率 Hz；SET_EQ_F0=基频 f0 Hz |
| 8-9  | crc16    | u16 LE | CRC16/CCITT-FALSE，覆盖 [0..7] |
| 10-15| page_payload | 6 B | 页0~4测量负载，显式小端 |

五页内容：页0=`f0:u32 + Upp_mV:u16`；页1=`Urms_mV:u16 + 分量数 + 状态 +
quality + 0`；页2~4=`阶次:u8 + 峰值幅度mV:u16 + 相位Q15:i16 + valid:u8`。
接收器要求页号严格0→4、模型代号一致、分量数≤3、首分量阶次为1；任何失败
都丢弃正在组装的暂存值，不覆盖上一组已发布结果。

CRC16/CCITT-FALSE：
- Poly `0x1021`，Init `0xFFFF`，RefIn/RefOut = false，XorOut `0x0000`。
- 只覆盖前 8 字节。

### 7.2 USART1 调试命令

在 `main()` 循环中通过 USART1 RX 中断接收单字符命令：

| 命令 | 作用 |
|------|------|
| `d` / `D` | 下一帧打印前 128 点 CSV（兼容旧 viewer） |
| `r` / `R` | 下一帧全 4096 点 binary dump（一次性） |
| `q` / `Q` | 切换 continuous binary 镜像（默认 ON） |
| `p` / `P` | 打印当前帧 summary（mean/min/max/pp/std/Fs） |
| `e` / `E` | 等效采样：打印重建后的 1 周期 256 点 CSV |
| `f` / `F` | 等效采样：打印重建后的 3 周期 768 点 CSV |

### 7.3 USART1 Binary 镜像帧格式

`dump_frame_binary()` 输出：

```text
[STX 0xAA 0x55] [seq u32 LE] [fs_hz u32 LE] [n u16 LE=4096]
    [n × u16 LE raw code (已 &0x0FFF)] [ETX 0x55 0xAA]
```

总长度 `12 + 4096·2 + 2 = 4206 B`，921600 波特率下约 71 ms/帧。

### 7.4 HMI TJC 串口指令

HMI 层通过 `HMI_SendCmd()` 发送 ASCII 命令，末尾加 `0xFF 0xFF 0xFF`。

- 设置文本：`t_vpp.txt="1.234"`
- 批量波形：`addt s_wave.id,0,<len>`，随后发送 `<len>` 个 8 位逻辑曲线值。
- 清屏：`cle s_wave.id,255`
- 切页：`page page0`

触摸事件由 HMI 屏主动回传：`0x65 <page_id> <component_id> <event> 0xFF 0xFF 0xFF`。

### 7.5 曲线坐标约定

- 重构时域波形使用 12 位显示码，2048 固定表示 0 V；正负方向采用同一增益。
- TJC `addt` 每点为 8 位逻辑值，128 是当前页面设计使用的横轴。
- 时域波形围绕 128 显示；频谱零幅值为 128，只向正半轴增长。
- 256 点频谱压缩为 240 点时首尾对齐，确保 `fft[255]` 的 500 kHz 端点可见。

主机测试可验证发送字节的坐标映射，ARM 构建可验证固件能够生成；两者都不能代替烧录后的 TJC 实屏目视验收。


## 8. 主循环与任务调度

### 8.1 主循环结构

```c
while (1) {
    /* 1. 处理 PC 串口命令 */
    if (g_uart_rx_flag) { ... }

    /* 2. AD9226 采集完成 */
    if (AD9226_IsDone()) {
        const uint16_t *buf = AD9226_GetBuf();

        /* 2.1 SPI1 与 H7 交换数据/命令 */
        AcqSpi_SendSamples(buf, 4096, fs);
        AcqSpi_RecvCmd(cmd_slot, 16);
        SpiCmd_ProcessRx(cmd_slot, 16);

        /* 2.2 等效采样重建 */
        if (AD9226_IsEqMode()) {
            EsReconstructPeriod(...);
            EsWaveform_Publish(...);
            screen_build_frame(&frame, buf, 4096, period, seq, periods);
            ScreenApp_SetFrame(&frame);
        }

        /* 2.3 普通采样重建 */
        if (!AD9226_IsEqMode()) {
            screen_build_frame(&frame, buf, 4096, NULL, seq, periods);
            ScreenApp_SetFrame(&frame);
        }

        /* 2.4 binary 镜像 / raw dump / summary */
        ...

        /* 2.5 启动下一帧 */
        AD9226_Start();
    }

    /* 3. 串口屏任务：HMI 通信、按键、渲染 */
    ScreenApp_Task();
}
```

### 8.2 显示刷新

`ScreenApp_Task()` 中：

- 每 `SCREEN_STATUS_INTERVAL_MS = 500 ms` 刷新连接状态；
- 当 `frame.sequence` 变化或每 `SCREEN_REFRESH_INTERVAL_MS = 300 ms` 触发 `ScreenView_RenderFrame()`；
- 渲染前合并 `ScreenI2cRawParamsFrame` 中的原始测量值（预留接口，当前 F4 采集端未启用 I2C 帧）。

## 11. 已知限制与调试建议

### 11.1 50 mVpp 小信号台阶

即使显示增益把 14 码的 50 mVpp 信号拉伸到 64 码，本质上仍是量化后的离散电平。当前通过以下手段改善：

- 小信号（< 150 mVpp）自动正弦拟合；
- 极小信号（< 80 mVpp）强制正弦拟合；
- 显示层按动态范围充满屏幕。

若仍不满足要求，可考虑：
- 增加 `ES_PERIOD_POINTS`（当前 256）到 512/1024，但需同步修改 FFT、显示缓冲区和 HMI 曲线容量；
- 在显示前加入低通插值或 sin(x)/x 重采样；
- 前端模拟增益放大，使小信号跨过更多 ADC 码。

### 11.2 FFT 频谱泄漏

FFT 长度固定 256，若 `f0·256/Fs` 不是整数，会出现主瓣分裂和泄漏。当前通过加 Hanning 窗抑制旁瓣，使正弦输入看起来是单峰。频率标签不再使用 FFT bin，而直接使用 H7 测得的 `f0`，避免 bin 量化误差。

### 11.3 谐波显示规则

只有幅度 ≥ 基波 5% 的谐波才会在屏上显示。若前端失真或噪声导致 2/3 次谐波被误判，可调高 `screen_extract_harmonics()` 中的阈值（当前 `/20`，即 5%）。

### 11.4 时序约束

- SPI1 一帧 8208 B @ 5.25 MHz 约 12.5 ms；采集 4096 点 @ 2.048 MHz 约 2 ms。主循环帧率受 SPI 通信限制，约为 67 fps。
- HMI `addt` 发送 768 字节 @ 921600 约 8 ms，加上 50+20 ms 延时，显示刷新不宜高于 20 Hz。当前 300 ms 刷新间隔留有很大余量。

### 11.5 常见排查

| 现象 | 排查方向 |
|------|----------|
| 屏幕无波形 | 检查 USART2 TX/RX、波特率 921600；检查 TJC 页面名 `page0` 和控件名 `s_wave`/`s_fft` |
| 波形静止但形状错 | 检查 H7 是否返回有效 `f0`；检查 `NormalReconstructPeriod` 的零穿越检测是否受噪声影响 |
| FFT 出现固定多峰 | 确认是否已加 Hanning 窗；检查 `screen_extract_harmonics` 阈值；用 `p` 查看实际 f0/Fs |
| 50 mVpp 全是台阶 | 确认 `screen_should_sine_fit()` 返回 true；必要时启用强制拟合 |
| SPI1 报错 | 检查 PA5/PA6/PA7 接线；确认 H7 已拉高 PA4 READY |
| AD9226 mean 异常 | 确认 PE9 时钟通、PC0~PC11 无错位、SMA 接地良好 |
